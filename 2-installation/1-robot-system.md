# 2.1 机器人系统

工业机器人是一种装备有自动控制、操纵和移动功能的机器，能够在工业环境中执行各种编程任务。协作机器人是一种工业机器人。

机器人系统由机器人主体和控制器组成，控制器控制机器人主体。教导手柄连接到控制器，用于设置和手动操作机器人系统。

* 机器人：执行工业环境中的各种任务，例如运输物体或组装零件。
* 控制器：根据通过教导手柄设定的程序设置协调机器人的动作。控制器的输入/输出端口可以用于与各种外部设备或装置接口。
* 教导手柄：该设备管理整个机器人系统。它可以用于教导机器人特定姿势或设置和控制程序。
