# 6.4	安全停止监控（SOS）违规时的恢复

安全停止监控（SOS）违规是指机器人电机开启且在停止状态下检测到运动。安全停止检测违规时，机器人将检测到瞬时运动并触发错误，因此可以在不移动机器人位置的情况下解除错误。

1. 将模式开关切换到手动模式。


2. 清除对机器人施加力的外部因素。


3.  안전 상태 모니터링 화면에서 각 영역의 상태가 **3. 在安全状态监控界面中检查各区域的状态是否显示为SAFE。**로 나타나는지 확인하십시오.


{% hint style="warning" %}
*[注意]**

* 解除错误后，请确认安全停止监控参数。
* 请在自动模式下打开电机，并确认错误是否再次发生。
* 如果再次发生相同错误，请检查该轴的电机和减速器。
{% endhint %}
