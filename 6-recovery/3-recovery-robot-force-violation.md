# 6.3 	从机器人力违规恢复

当施加外部力量或机器人内部使用的力量大小超过安全标准时，会发生机器人力违规，例如碰撞检测、功率和动量监测违规。 根据违规的原因，可以清除错误。

<mark style="color:green;">**当由于施加在机器人上的外部力量而发生违规时**</mark>

1. 移除施加在机器人上的外部因素。


2. 将模式开关切换至手动，以进入手动模式。


3. 在安全状态监控屏幕中，确认各区域的状态显示为 **SAFE**。


{% hint style="warning" %}
**\[注意]**

* 清除错误后，重新检查安全功能设置、工具数据和工作程序的教学位置和速度。
{% endhint %}
