# 6.3	机器人力违规时的恢复

机器人力违规是指施加外部力量或机器人内部使用的力的大小超过安全标准，包括碰撞检测、功率及动量监控违规。根据违规发生的原因，可以解除错误。

<mark style="color:green;">**当从外部对机器人施加力而发生违规时**</mark>

1. 清除对机器人施加力的外部因素。


2. 将模式开关切换到手动模式。


3. 在安全状态监控界面中检查各区域的状态是否显示为 **SAFE**。


{% hint style="warning" %}
**\[注意]**

* 解除错误后，请重新确认安全功能设置、工具数据、作业程序的示教位置及速度。
{% endhint %}
