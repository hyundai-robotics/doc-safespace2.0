# 安全预防措施

为了确保产品的正确使用和用户安全，防止财产损失，请在使用产品之前确保了解以下安全预防措施。

### <mark style="color:green;">危险</mark>

{% hint style="danger" %}
<strong>[危险] 紧急危险</strong>: 不遵守可能导致工人死亡或严重受伤。
{% endhint %}

* 对整个系统进行风险评估，而不是单个设备。将其他设备连接到产品可能会增加产品的风险或产生新的风险。当集成机器人系统中的每个设备具有不同的风险水平时，基于风险水平最高的设备准备安全装置以应对危险。
* 熟悉手册中描述的产品安装内容，并根据说明安装机器人产品和其他设备。
* 如果发生产品故障或损坏等问题，立即停止使用并联系客户支持团队。

### <mark style="color:green;">警告</mark>

{% hint style="warning" %}
<strong>[警告] 潜在危险</strong>: 如果不遵守，工人可能会受伤，产品可能会严重损坏，导致财产损失。不遵守可能导致工人受伤、产品严重损坏或财产损失。
{% endhint %}

* 根据风险评估结果采取适当的安全措施，并准确指定机器人安全安装范围。否则，在机器人操作时，产品可能会损坏或用户可能会受伤。
* 机器人应用系统制造商和机器人用户应熟悉手册的内容并完成产品操作培训。
* 为了保障工人和用户的安全，请在安装产品之前准备适当的安全设施，如安全围栏。
* 确保有足够的空间，让机器人手臂可以自由移动。如果安装空间不足，产品可能会损坏或用户可能会受伤。
* 检查规格信息，使用适当的固定螺钉并以规定的扭矩拧紧。如螺钉松动，机器人可能会从安装位置分离并掉落或受到损坏。
* 注意避免液体、灰尘、金属粉末或其他导电物质进入产品的连接部位（电源和电缆）。此外，不要用尖锐物体刺入连接部件，也不要在连接电缆时施加过大的力量。否则，由于腐蚀或连接端子瞬时短路，产品可能会爆炸或着火。
* 检查接线信息，并根据设备类型使用适当的端子连接设备。特别是，安全装置必须连接到安全装置端子，因为连接到通用端子无法保证安全功能。
* 切勿使用损坏的电缆，并且在使用产品时不要断开电源。否则，可能会导致电击、火灾、故障或受伤。
* 长时间使用产品会产生热量，这会造成烧伤等受伤风险。当需要在长时间使用后触摸产品时，请先关闭电源并保持该状态超过1小时，以充分冷却后再进行操作。
* 切勿未经授权安装、修改、拆卸或修理产品。否则，可能会导致故障和事故。此外，我们不对因上述原因造成的产品损坏和故障负责。

### <mark style="color:green;">注意</mark>

{% hint style="warning" %}
<strong>[注意] 低风险因素</strong>: 不遵守可能导致工人轻微受伤或财产损失，包括产品损坏。
{% endhint %}

* 切勿未经授权安装、修改、拆卸或修理产品。此外，未经我们专家的授权，任何人不得修改产品或附加零件。否则，在产品故障情况下，您将无法获得免费服务或质量保证服务。
* 安装和修理产品时，请联系客户支持团队请求专家。
* 不要在灰尘或肮脏的地方安装和使用产品。否则，产品可能会因灰尘或异物而故障或性能问题。
* 不要在磁性地方、受磁性影响的地方或有电磁干扰的地方安装和使用产品。否则，产品可能会因磁性而受到损坏或出现性能问题。
* 在操作产品时，不要穿着宽松的衣服或首饰，如果您有长发，请把它扎起来，以避免头发被机器人关节等夹住。
* 在产品操作时，切勿进入操作范围或接触机器人。存在受伤风险。
* 以包装状态运输产品，以避免损坏，并将其存放在低湿度的干燥地点。产品可能由于包装材料内部的湿气而损坏或出现故障。
* 将产品存放在干净、凉爽和干燥的地方，避免温度和湿度变化容易的地方。
* 在运输产品时，保持正确的姿势并与两人或更多人合作。您可能会受到腰部、手臂或腿部等身体部位的伤害。
* 使用提升设备运输产品时，请遵守相关国家和地区的安全法规和设备使用指南。
* 熟悉手册中的运输内容，并按照说明运输产品。我们不对因客户运输产品而造成的产品损坏和故障负责。
