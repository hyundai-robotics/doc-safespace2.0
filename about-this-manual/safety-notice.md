# 安全注意事项

为了确保产品的正确使用和用户安全，并防止财产损失，请务必在使用产品前熟悉以下安全注意事项。

### <mark style="color:green;">危险</mark>

{% hint style="danger" %}
*\[危险] 紧急危险**：若不遵守，可能导致工作人员死亡或重伤。
{% endhint %}

* 请对整个系统而非单个装置实施风险评估。若将其他装置连接到本产品，可能会提高产品的危险度或产生新的危险。若机器人集成系统各装置的危险度不同，请以危险度最高的装置为基准准备安全装置并应对危险。
* 请熟悉说明书中描述的产品安装内容，并按照指示安装机器人产品及其他设备。
* 如果产品发生故障或损坏等问题，请立即停止使用并联系客服中心。

### <mark style="color:green;">Warning</mark>

{% hint style="warning" %}
*\[警告] 潜在危险**：若不遵守，可能导致工作人员受伤或产品严重损坏等财产损失。
{% endhint %}

* 请根据风险评估结果采取适当的安全措施，准确指定机器人安全安装范围。否则，在机器人运行中，产品可能会损坏或用户可能会受伤。
* 机器人应用系统制造商或机器人用户应熟悉说明书的内容，并完成产品操作培训。
* 为确保操作员和用户的安全，在安装产品之前，请务必安装安全防护栏等适当的安全设施。
* 请确保机械臂能够自由移动的充分空间。如果安装空间不充裕，在机器人运行中，产品可能会损坏或用户可能会受伤。
* 请确认规格信息，使用合适的固定螺钉并按照指定的扭矩来进行拧紧。如果螺钉松动，机器人可能会从安装位置脱离，导致坠落或损坏。
* 请注意避免液体、灰尘、金属粉末等导电异物进入产品的连接部（电源及电缆）。 此外，请勿用尖锐物体刺入连接部，也不要在连接电缆时施加过大的力量。连接端子的腐蚀或暂时性短路可能会导致产品爆炸或引发火灾。
* 请确认配线信息，并根据设备类型使用合适的端子来连接设备。特别是，如果将安全装置连接到普通端子，则无法保证安全功能，因此必须将其连接到专用于安全装置的端子。
* 切勿使用已损坏的电缆，并且在产品使用过程中不要断开电源，否则，可能会导致触电、火灾、故障及人身伤害。
* 长时间使用产品会产生热量，存在烫伤等伤害的风险。如果必须接触产品，请先关闭电源，静置1小时以上，待产品充分冷却后再进行操作。
* 切勿擅自安装、改装、拆卸或维修产品。否则，可能会导致故障和事故的发生。此外，对于因此造原因的产品损坏或破损，本公司概不负责。

### <mark style="color:green;">Caution</mark>

{% hint style="warning" %}
*\[注意] 低危险因素**：若不遵守，可能导致工作人员受轻伤或产品损坏等财产损失。
{% endhint %}

* 请勿擅自安装、改装、拆卸或维修产品。 此外，禁止除本公司所属专家以外的任何人未经授权擅自改装产品或安装部件。因上述行为导致产品故障时，则将无法享受免费服务及质量保证服务。
* 若要安装或维修产品，请联系客服中心并向专家询问。
* 请勿在有大量灰尘或脏污的地方安装和使用本产品，否则可能因灰尘或异物引起产品故障或性能异常。
* 请勿在有磁性或受磁性影响的地方，或存在电磁干扰的地方安装和使用产品。磁性可能会导致产品损坏或性能异常。
* 运行产品时，请勿穿着宽松的衣服或佩戴首饰。如果工作人员的头发较长，请把头发扎在后面，以免头发卷入机器人关节等。
* 产品运行的过程中，请勿进入其运行范围内或触碰机器人，存在受伤的风险。
* 请将产品在包装好的状态下搬运以避免损坏，并存放在湿度低的干燥场所。包装材料内部的湿气可能会导致产品损坏或故障。
* 请将产品存放在清洁、阴凉、干燥的地方，避免存放在温度和湿度会容易发生变化的地方。
* 搬运产品时，请保持正确的姿势，应由两人以上共同操作。否则可能会对腰部、手臂、腿部等身体部位造成伤害。
* 当使用吊运设备来搬运产品时，请务必遵守相关国家和地区的安全规定及设备使用指南。
* 请仔细阅读说明书中的搬运内容，并按照指示搬运产品。因客户运输产品而导致产品损坏或破损时，本公司概不负责。
