# Über dieses Handbuch

Dieses Handbuch beschreibt die Sicherheits-, Installations-, Verwendungs- und Wartungsmethoden für Hyundai Robotics SafeSpace2.0.

Machen Sie sich vor der Verwendung des Produkts gründlich mit dem Inhalt des Handbuchs vertraut. Bewahren Sie das Handbuch außerdem in Ihrer Nähe auf, damit Sie bei Bedarf jederzeit darin nachschlagen können.

Dieses Handbuch kann Kunden, die Produkte von Hyundai Robotics erwerben, als Referenz oder als internes Schulungsmaterial zur Verfügung gestellt werden.

Dieses Handbuch basiert auf Standard-Spezifikationen, daher können einige Inhalte je nach Modell des von Ihnen erworbenen Produkts abweichen. Darüber hinaus können die Inhalte und Spezifikationen dieses Handbuchs ohne vorherige Ankündigung geändert werden, um die Produktleistung zu verbessern. Hyundai Robotics übernimmt keine Verantwortung für Situationen, die durch ungenaue Inhalte oder Tippfehler verursacht werden.. Ausführliche Informationen zu Änderungen finden Sie auf unserer Website ([www.hyundai-robotics.com](https://www.hyundai-robotics.com)).
