# 3.2 限制

SafeSafe2.0 存在以下限制。请在配置该功能前确认其适用性。


|  **项目** |                       **描述**                       |
| :-------: | :------------------------------------------------: |
| 支持的机器人 | 六轴工业机器人、协作机器人 |
| 不支持的机器人 | 平板探测器机器人、喷涂机器人、龙门机器人 | 
| 支持的轴 | 最多 8 个轴（对于 9 个或更多轴的系统，安全功能只能配置在第 7 轴和第 8 轴上） |
| 不支持的机器人轴 | 伺服枪轴、与机器人组合的附加轴（龙门机器人） |
