# 3.2 Einschränkungen

SafeSafe 2.0 weist die folgenden Einschränkungen auf. Bitte prüfen Sie deren Anwendbarkeit, bevor Sie die Funktion konfigurieren.


|  **Artikel** |                       **Beschreibung**                       |
| :-------: | :------------------------------------------------: |
| Unterstützte Roboter | 6-Achs-Industrieroboter, kollaborative Roboter |
| Nicht unterstützte Roboter | FPD-Roboter, Lackierroboter, Portalroboter | 
| Unterstützte Achsen | Bis zu 8 Achsen (Bei Systemen mit 9 oder mehr Achsen können Sicherheitsfunktionen nur für die Achsen 7 und 8 konfiguriert werden) |
| Nicht unterstützte Roboterachsen | Servogun-Achsen, zusätzliche Achsen in Kombination mit Robotern (Portalroboter) |
