# 3.2 제한 사항

SafeSapce2.0은 아래와 같은 제한 사항을 가지고 있습니다. 적용 가능여부를 확인 후 기능 설정을 하시기 바랍니다. 


|  **항목** |                       **설명**                       |
| :-------: | :------------------------------------------------: |
| 지원 로봇 |  6축 산업용 로봇, 협동 로봇  |
| 미지원 로봇 | FPD 로봇, 도장 로봇, 갠트리 로봇 | 
| 지원 축 수 | 최대 8축 (9축 이상 시스템의 경우 안전기능은 7,8축에 대해서만 설정 가능)  |
| 미지원 로봇 축 |   서보건 축, 로봇과 결합된 부가축(갠트리 로봇)  |
