# 3.2.2 速度及位置监控

机器人在指定距离和速度内运行。

速度及位置监控模式是通过使用能够检测人员位置和速度的传感器，根据机器人与人员之间的距离和相对速度成比例地控制机器人运行速度的模式。对于检测距离的外部传感器输入，可使用减速模式进行控制。
