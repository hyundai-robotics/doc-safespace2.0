# 3.1 术语说明

### <mark style="color:green;">机器人监控功能</mark>&#xD;

用于监控机器人速度、力和动量的基准参数。

* **关节角度监控**

监控各轴关节的位置。当其超过基准值时则执行由用户设置的安全停止。

* **关节速度监控**

监控各轴关节的速度。当超过基准值时我执行由用户设置的安全停止
    
* **安全停止监控（SOS, Safe Operating Stop）**

监控各轴是否在无滑动的状态下保持停止状态。当其超过基准值时则执行停止0。

* **TCP位置监控**

监控安全工具模型是否发生安全区域违规。当侵入区域时则执行由用户设置的安全停止。
    
* **TCP方向监控**

监控工具方向是否偏离指定范围。当超过基准值时则执行由用户设置的安全停止。
    
* **TCP速度监控**

监控工具中心点的速度。当其超过基准值时则执行由用户设置的安全停止。
    
* **功率监控**

监控机器人的功率。当其超过基准值时则执行由用户设置的安全停止。
    
* **动量监控**

监控机器人的动量。当其超过基准值时则执行由用户设置的安全停止。


* **碰撞检测**

当因施加外力于机器人而其超过允许值时，则执行由用户设置的安全停止。


### <mark style="color:green;">安全布局</mark>

用于监控TCP位置和方向的基准安全区域和工具区域的参数。

* **安全区域**

工具的工作区域及保护区域的总称
* **工作区域**

指机器人执行作业的区域。当工具及机器人肘部模型偏离工作区域时，则执行安全停止。
* **保护区域**

指需要防止机器人进入的区域。当工具及机器人肘部模型侵入保护区域时，则执行安全停止。
* **安全工具建模**

为了监控TCP位置及方向，将安装在机器人上的工具建模为球体和圆锥体。
* **安全机器人建模**

将机器人的2轴和3轴建模为胶囊，并监控其与安全区域的距离。



### <mark style="color:green;">安全停止</mark>&#xD;

当发生安全违规时，为使机器人处于安全状态而停止机器人，停止方法有3种。有关各停止方法的详细信息，请参阅“ISO 13850”或“IEC 60204-1”。

* **停止0**

立即切断所有关节的电机电源并停止（非受控停止）。
* **停止1**

所有关节的电机减速后停止，之后切断电机电源（受控停止）。机器人继续沿程序路径减速停止，机器人停止后立即切断电源。
* **停止2**

所有关节的电机减速后执行安全停止监控（SOS, Safe Operating Stop）。此时所有电机保持供电状态。


停止1和停止2通过减速时间及距离监控减速过程。

* **停止时间**

监控从开始减速到实际停止的时间，如果机器人未在已设定时间内停止，则执行停止0来立即切断电机电源。
* **停止距离**

监控从开始减速到实际停止的TCP距离，如果机器人未在已设定距离内停止，则执行停止0立即切断电机电源。



### <mark style="color:green;">安全运动调优</mark>&#xD;

此功能可自动调整机器人运动，避免超出设定的参数范围。
运动调优过程中会考虑以下参数：

* **关节速度**

* **TCP速度**

* **功率**

* **动量**

* **停止时间**

* **停止距离**
