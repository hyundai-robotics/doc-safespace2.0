# 3.3.4.2 扩展安全输入输出信号

设置附加安全输入输出信号的参数。由8个输入信号和8个输出信号组成，全部以双通道信号运行。
**\[系统 > 8: 安全系统 > 2: 参数设置 > 3: 安全输入输出 > 3: 扩展输入输出]** 菜单中可以设置参数值。 

## 1. 附加安全输入输出信号

<p align="center">
<img src="../../../_assets/safety_io/add_io.png"></img>
<em><p align="center">扩展输入输出设置界面</p></em>
</p>

| 参数 [单位]             | 说明                                                                                                                                       | 输入范围       | 默认值 |
|:---------------------------:|:----------------------------------------------------------------------------------------------------------------------------------------:|:--------------:|:------:|
| 启用                       | 设置扩展安全输入输出信号的启用 / 禁用。                                                                                       | 启用 / 禁用 | 禁用 |
| 滤波时间 <br>[msec]          | 各输入通道必须在**滤波时间**内输入恒定信号，才能作为有效信号处理。<br>只能输入5的倍数值。                           | 0 ~ 500        | 100    |
| 不一致允许时间 <br>[msec]     | 扩展安全输入输出在两个双通道信号相同时才作为有效信号处理。<br>若两个信号在**不一致允许时间**以上互不相同，则将发生报警。<br>只能输入5的倍数值。 | 0 ~ 5000       | 1000   |
| 输入错误保持时间 <br>[msec] | 各通道在发生错误后，即使该错误已解除，也要经过已设定的时间后才能从Fail-Safe状态转换为当前输入状态。<br>只能输入5的倍数值。             | 0 ~ 65530      | 1000   |
| 输出错误保持时间 <br>[msec] | 各通道在发生错误后，即使该错误已解除，也会在已设定的时间内保持**Open (Fail-safe)**状态。<br>之后转换为正常输出。<br>只能输入5的倍数值。   | 0 ~ 65530      | 1000   |
