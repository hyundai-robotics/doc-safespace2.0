# 3.3.4.1 基本安全输入输出信号

设置安全输入输出信号的参数。  
输入信号有4个，输出信号有1个，全部以双通道信号运行。
**\[系统 > 8: 安全系统 > 2: 参数设置 > 3: 安全输入输出 > 2: 基本输入输出]** 菜单中可以设置参数值。 

## 1. 输入信号设置

<p align="center">
<img src="../../../_assets/safety_io/def_input.png"></img>
<em><p align="center">基本输入输出设置界面（输入）</p></em>
</p>

| 参数 <br>[单位]          | 说明                                                                                                                                       | 输入范围       | 默认值 |
|:------------------------:|:----------------------------------------------------------------------------------------------------------------------------------:|:--------------:|:------:|
| 脉冲测试                 | 设置各通道是否使用脉冲测试。                                                                                                     | 启用 / 禁用 | 禁用 |
| 错误保持时间 <br>[msec] | 各通道在发生错误后，即使该错误已解除，也要经过**错误保持时间**后才能从Fail-Safe状态转换为当前输入状态。<br>只能输入5的倍数值。 | 0 ~ 65530      | 1000   |
| 滤波时间 <br>[msec]      | 各通道必须在已设定的**滤波时间**内输入相同信号才能作为有效信号处理。<br>只能输入5的倍数值。                       | 0 ~ 500        | 100    |
| 不一致允许时间 <br>[msec] | 基本输入信号在两个双通道信号相同时才作为有效信号处理。<br>若两个信号在设定的**不一致允许时间**以上互不相同，则将发生报警。<br>只能输入5的倍数值。 | 0 ~ 5000       | 1000   |

## 2. 输出信号设置

<p align="center">
<img src="../../../_assets/safety_io/def_output.png"></img>
<em><p align="center">基本输入输出设置界面（输出）</p></em>
</p>

| 参数 <br>[单位]          | 说明                                                                                                                                       | 输入范围       | 默认值 |
|:------------------------:|:----------------------------------------------------------------------------------------------------------------------------------:|:--------------:|:------:|
| 脉冲测试                 | 设置各通道是否使用脉冲测试。                                                                                                     | 启用 / 禁用 | 禁用 |
| 错误保持时间 <br>[msec] | 各通道在发生错误后，即使该错误已解除，也会在**错误保持时间**内保持**Open（Fail-safe）**状态。之后转换为正常输出。<br>只能输入5的倍数值。 | 0 ~ 65530      | 1000   |
