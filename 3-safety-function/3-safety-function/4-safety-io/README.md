# 3.3.4 Sicherheitseingang/-ausgang

Grundlegende Informationen zum Sicherheitseingang/-ausgang

## Der Sicherheitseingang/-ausgang des Hi7 lässt sich wie folgt unterteilen:

- Basissicherheitseingang (4 Kanäle x doppelter Eingang)
- Erweiterter Sicherheitseingang (8 Kanäle x doppelter Eingang)
- Basissicherheitsausgang (1 Kanal x doppelter Eingang)
- Erweiterter Sicherheitsausgang (8 Kanäle x doppelter Eingang)
- PROFIsafe Kommunikations-Sicherheitseingang (64 Punkte)
- PROFIsafe-Kommunikations-Sicherheitsausgang (64 Punkte)
- CIP-Safety-Kommunikations-Sicherheitseingang (64 Punkte)
- CIP-Safety-Kommunikations-Sicherheitsausgang (64 Punkte)
