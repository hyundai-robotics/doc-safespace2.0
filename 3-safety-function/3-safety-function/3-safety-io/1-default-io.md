# 3.3.3.1 安全输入输出信号

设置安全输入输出信号的参数。
输入信号有4个，输出信号有1个，全部以双通道信号运行。


## 1. 输入信号设置

![!Default Input Image](../../../_assets/safety_io/def_input.PNG)

- **- Pulse Test：设置各通道是否使用Pulse Test。** : 각 채널별로 Pulse Test 사용 여부를 설정합니다.
- **- Error Latch时间：该通道发生错误时，即使错误恢复，也会在设定时间后从Fail-Safe状态转换为当前输入状态。（单位：msec）** : 해당 채널에서 에러가 발생하면, 에러가 복구되더라도 설정된 시간 이후에 Fail-Safe 상태에서 현재 입력 상태로 전환됩니다. (단위 : msec)
- **- 滤波时间：各通道在已设定的滤波时间内必须输入相同信号才能作为有效信号处理。（单位：msec）** : 각 채널별로 설정된 **- 滤波时间：各通道在已设定的滤波时间内必须输入相同信号才能作为有效信号处理。（单位：msec）** 동안 동일한 신호가 입력되어야 유효한 신호로 처리됩니다. (단위 : msec)
- **- Discrete时间：基本输入信号在两个双通道信号相同时才作为有效信号处理。若两个信号在已设定的Discrete时间以上互不相同，则会发生报警。（单位：msec）** : 기본 입력 신호는 두 개의 이중 신호가 동일할 때 유효한 신호로 처리됩니다. 두 신호가 설정된 **- Discrete时间：基本输入信号在两个双通道信号相同时才作为有效信号处理。若两个信号在已设定的Discrete时间以上互不相同，则会发生报警。（单位：msec）** 이상 서로 다르면 알람이 발생합니다. (단위 : msec)


## 2. 输出信号设置

![!Default Output Image](../../../_assets/safety_io/def_output.PNG)

- **- Pulse Test：设置各通道是否使用Pulse Test。** : 각 채널별로 Pulse Test 사용 여부를 설정합니다.
- **- Error Latch时间：该通道发生错误时，即使错误恢复，输出触点也会在已设定时间内保持Open（Fail-safe）状态。之后，转换为正常输出。（单位：msec）** : 해당 채널에서 에러가 발생하면, 에러가 복구되더라도 설정된 시간 동안 출력 접점은 **- Error Latch时间：该通道发生错误时，即使错误恢复，输出触点也会在已设定时间内保持Open（Fail-safe）状态。之后，转换为正常输出。（单位：msec）** 상태를 유지합니다. 이후 정상 출력으로 전환됩니다. (단위 : msec)
