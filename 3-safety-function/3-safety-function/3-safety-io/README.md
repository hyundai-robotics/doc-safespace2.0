# 3.3.3 안전 입/출력

안전 입출력의 기본 정보

## Hi6a의 안전 입출력은 다음과 같이 나뉠 수 있습니다.

- 기본 안전 입력 (4ch x 이중입력)
- 확장 안전 입력 (8ch x 이중입력)
- 기본 안전 출력 (1ch x 이중입력)
- 확장 안전 출력 (8ch x 이중입력)
- PROFIsafe 통신 안전 입력 (64 점)
- PROFIsafe 통신 안전 출력 (64 점)
- CIP Safety 통신 안전 입력 (64 점)
- CIP Safety 통신 안전 출력 (64 점)
