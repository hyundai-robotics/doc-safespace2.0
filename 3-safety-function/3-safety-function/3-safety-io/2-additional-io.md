# 3.3.3.2 附加安全输入输出信号

设置附加安全输入输出信号的参数。
由8个输入信号和8个输出信号组成，全部以双通道信号运行。

## 1. 附加安全输入输出信号

![!Additional Input Image](../../../_assets/safety_io/add_io.PNG)

- **- Enable：未使用（不启用）** : 미사용
- **- 滤波时间：各输入通道在已设定的滤波时间内必须输入一定的信号才能作为有效信号处理。（单位：msec）** : 각 입력 채널별로 필터 시간 동안 일정한 신호가 입력되어야 유효한 신호로 처리됩니다. (단위 : msec)
- **- Discrete时间：Additional Safety Input在两个双通道信号值相同时作为有效信号处理，若这两个信号在Discrete时间以上不同，则会发生报警。（单位：msec）** :  Additional Safety Input 은 2개의 이중 신호가  같은 값일때 유효한 신호로 처리되고 이 2개의 신호가 **- Discrete时间：Additional Safety Input在两个双通道信号值相同时作为有效信号处理，若这两个信号在Discrete时间以上不同，则会发生报警。（单位：msec）** 보다 큰 시간 동안 다르게 되면 알람이 발생하게 됩니다. (단위 : msec)
- **- Input Error Latch时间：该通道发生错误时，即使错误恢复，也会在设定时间后从Fail-Safe状态转换为当前输入状态。（单位：msec）** :  해당 채널에서 에러가 발생하면, 에러가 복구되더라도 설정된 시간 이후에 Fail-Safe 상태에서 현재 입력 상태로 전환됩니다. (단위 : msec)
- **- Output Error Latch时间：该通道发生错误时，即使错误恢复，输出触点也会在设定时间内保持Open（Fail-safe）状态。之后转换为正常输出。（单位：msec）** : 해당 채널에서 에러가 발생하면, 에러가 복구되더라도 설정된 시간 동안 출력 접점은 **- Output Error Latch时间：该通道发生错误时，即使错误恢复，输出触点也会在设定时间内保持Open（Fail-safe）状态。之后转换为正常输出。（单位：msec）** 상태를 유지합니다. 이후 정상 출력으로 전환됩니다. (단위 : msec)
