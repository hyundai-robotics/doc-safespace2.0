# 3.3.2 机器人监控功能

机器人安全参数包括用于监控安全功能的限值和停止方法。

每个安全功能都可以配置不同的激活条件、违规停止方法和限值。

要配置机器人安全参数，请按以下步骤进入菜单：

* **\[系统 > 8：安全系统 > 2：参数设置 > 1：机器人限值]**
****

以下安全功能可在“机器人限制”菜单中进行配置：

* **关节活动范围**：限制机器人每个轴的运动范围。
* **关节速度**：限制机器人的运动速度，防止其超过每个轴的速度限制。
* **关节停止**：在执行停止 2 后，通过检查每个轴的异常运动来监控机器人的停止状态。
* **TCP 速度**：根据 TCP 标准，将机器人的速度限制在指定速度。
* **碰撞检测**：限制机器人与工人发生碰撞时的冲击力。
* **RePlan**：根据外部输入调整机器人速度，以在协作操作模式下执行[3.2.2 速度和位置监控](../../2-collaborative-operation-mode/2-speed-separation-monitoring.md)。
* **力检测**：限制机器人与工人发生碰撞时的冲击力。
* **动量**：限制机器人与工人发生碰撞时的能量和冲击载荷。


{% hint style="warning" %}
**\[注意]**：操作人员和用户在配置机器人安全功能前必须进行风险评估，以确保机器人周围人员和设备的安全。根据评估结果，进行以下配置：

* 设置密码等，以防止未经授权更改安全配置。
* 配置安全相关功能和接口。
* 操作机器人前，验证设置的准确性。
* 确认所有安全功能配置和设置均符合风险评估要求。
{% endhint %}
