# 3.3.2.3 关节停止监控

停止监控功能会在机器人停止操作期间监控每个轴的异常运动。如果超出设定的限值，则会立即触发安全停止（停止 0）。

参数值可在 **\[系统 > 8：安全系统 > 1：参数设置 > 1：机器人限值 > 3：关节停止]** 菜单中设置。

<p align="center">
<img src="../../../_assets/joint_sos_param.png"></img>
<em><p align="center">停止监控参数设置界面</p></em>
</p>

|  **参数** |                       **描述**                       |  **默认设置**  |
| :-------: | :------------------------------------------------: | :----------: |
| 激活 | <p>功能是否激活</p><p>(无效/有效/安全 I/O)</p> | 无效 |
| 关节激活 | <p>每个关节是否激活</p><p>(激活/禁用)</p> | 禁用 |
| <p>允许范围</p><p>[度]</p> | <p>每个关节的角度限制值</p><p>(0.0 ~ 3.0)</p> | 0.001 |

{% hint style="warning" %}
**\[注意]**：如果停止监控参数被违反，请务必在重新启动之前检查机器人的运动是否正常。
{% endhint %}
