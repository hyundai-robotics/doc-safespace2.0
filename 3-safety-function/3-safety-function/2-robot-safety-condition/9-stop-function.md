# 3.3.2.9 停止设置

为每个安全功能设置相应的安全停止类型。安全停止功能会在发生安全违规事件时将机器人停止到安全状态。共有三种类型：所有类型的安全停止功能均符合 IEC 61800-5-2 标准的 4.2.2.4 要求。

* **停止 0**：立即切断关节模块中所有电机的电源并停止运行。
* **停止 1**：关节模块中所有电机减速并停止运行。然后切断电机电源。
* **停止 2**：关节模块中所有电机减速，并启动 SOS（安全运行停止）功能。所有电机保持供电。

因安全功能违规而导致的停止类型在特定功能的参数设置菜单中设置。
符合 ISO 10218-1 标准的停止类型设置如下：

参数值可在 **\[系统 > 8：安全系统 > 1：基本设置 > 2：停止设置]** 菜单中设置。
