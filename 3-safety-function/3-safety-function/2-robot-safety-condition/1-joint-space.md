# 3.3.2.1 关节角度限制设置

关节区域设定参数是用于监控机器人关节空间安全功能的限值。如果监控值被违反，则会立即激活指定的安全停止点（停止点 0、停止点 1 或停止点 2）。

<p align="center">
<img src="../../../_assets/joint_space.PNG"></img>
<em><p align="center">关节区域设置示例（S轴）</p></em>
</p>

您可以在 **\[系统 > 8：安全系统 > 2：参数设置 > 1：机器人限制 > 1：关节区域]** 菜单中设置参数值。

<p align="center">
<img src="../../../_assets/joint_space_param.png"></img>
<em><p align="center">关节区域参数设置屏幕</p></em>
</p>


|  **参数** |                       **说明**                       |  **默认设定值**  |
| :-------: | :------------------------------------------------: | :----------: |
| 类型 | <p>安全区域类型</p><p>（工作区域/保护区域）</p> | 工作区域 |
| 激活 | <p>功能是否激活</p><p>（无效/有效/安全 I/O）</p> | 无效 |
| 停止方式 | <p>功能违规时的停止方式</p><p>（停止 0 / 停止 1 / 停止 2 / 不停止）</p> | 停止 1 |
| 关节激活 | <p>各关节是否激活</p><p>（激活/未激活）</p> | 未激活 |
| <p>最小值</p><p>[度]</p> | <p>各关节的角度限制值</p><p>（-360.0 ~ 360.0）</p> | -360.0 |
| <p>最大值</p><p>[度]</p> | <p>各关节角度限制</p><p>(-360.0 ~ 360.0)</p> | 360.0 |

{% hint style="warning" %}
*\[注意]**：安全功能基于已设定的区域进行监控。设定区域时应考虑停止距离，驱动前必须进行验证。
{% endhint %}
