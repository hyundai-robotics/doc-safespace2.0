# 3.3.2.6 Re plan 环境

重新规划功能会根据外部安全传感器接收到的信号调整机器人的速度。机器人的运行速度会根据输入信号对应的减速度进行调整，并在延迟一段时间后以相应的速度监测 TCP 速度。

如果延迟时间不足或机器人减速不足，导致违反 TCP 速度限制，则会立即触发安全停止（停止 0、停止 1、停止 2）。

您可以在 **\[系统 > 8：安全系统 > 2：参数设置 > 1：机器人限制 > 6：重新规划]** 菜单中设置参数值。

<p align="center">
<img src="../../../_assets/3/re_plan.png"></img>
<em><p align="center">Re plan 设置屏幕</p></em>
</p>

|  **参数** |                       **说明**                       |  **默认设定值**  |
| :-------: | :------------------------------------------------: | :----------: |
| Re plan | <p>是否根据输入信号使用速度控制功能</p><p>(启用/禁用)</p> | 禁用 |
| <p>延迟时间</p><p>[毫秒]</p> | <p>使用重新规划更改速度时，延迟时间后监测更改后的速度限制值</p><p>(0 ~ 1000)</p> | 2000 |
| <p>速度限制值</p><p>[毫米/秒]</p> | <p>重新规划后的 TCP 速度限制值</p><p>(0 ~ 50000)</p> | 50000 |
| <p>速度比率</p><p>[%]</p> | <p>重新规划时使用的减速比率</p><p>(0 ~ 100)</p> | 100 |
| <p>输入信号</p><p>[类型，编号]</p> | <p>重新规划的输入信号</p><p>( [无，-] / [安全输入，1~8] / [PROFIsafe，1~64] )</p> | 0 |

{% hint style="warning" %}
* 设置速度限制时，务必考虑停止时间，并遮盖机器人以防止碰撞和人员受伤。
* 高速和大载荷会随着机器人动能的增加而增大，从而增加机器人的冲击力。因此，如果机器人与外部物体碰撞，可能会造成严重冲击。在协作空间中，请保持安全的速度和载荷。
{% endhint %}
