# 3.3.2.7 功率设置

此功能用于监控机器人产生的力是否超过允许限值。如果监控结果超出限值，则会立即触发安全停止（停止 0、停止 1 或停止 2）。

您可以在 **\[系统 > 8：安全系统 > 2：参数设置 > 1：机器人限值 > 7：功率]** 菜单中设置参数值。

<p align="center">
<img src="../../../_assets/power_param.png"></img>
<em><p align="center">电源设置屏幕</p></em>
</p>

| **参数** | 　　　　　　　　　**说明**                                                  |  **默认设定值** |
| :------: | :----------------------------------------------------------------: | :---------: |
| 激活 | <p>功能是否激活</p><p>(无效 / 有效 / 安全 I/O)</p> | 无效 |
| 停止方式 | <p>功能违规时的停止方式</p><p>(停止 0 / 停止 1 / 停止 2 / 不停止)</p> | 停止 1 |
| 运动调整 | <p>调整运动至不超过机器人功率限制的状态</p><p>(启用 / 禁用)</p> | 禁用 |
| <p>最大功率</p><p>[瓦]</p> | <p>机器人功率限制</p><p>(80 ~ 1000)</p> | 1000 |

{% hint style="warning" %}
* 高速和大载荷会显著增加机器人的动能，从而增大其冲击力。因此，与外部物体碰撞可能会造成严重冲击。在协作空间中，请保持安全的速度和载荷。
* 如果工具信息和附加重量的设置与实际值不同，可能会导致误检。请在使用此功能前仔细核对相关信息。
{% endhint %}
