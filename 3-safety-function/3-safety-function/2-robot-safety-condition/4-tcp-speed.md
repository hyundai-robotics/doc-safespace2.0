# 3.3.2.4 TCP速度限制设置

此功能监控与机器人坐标系统相关的TCP速度。如果发生监控违规，将立即激活安全停止（停止0、停止1或停止2）。

您可以在`[系统 > 10: 安全系统 > 2: 参数设置 > 1: 机器人限制 > 4: TCP速度]`菜单中设置参数值。

<p align="center">
<img src="../../../_assets/3/tcp_speed.png"></img>
<em><p align="center">TCP速度参数设置屏幕</p></em>
</p>


| **参数** |                                  **描述**                                  |  **默认设置** |
| :------: | :----------------------------------------------------------------: | :---------: |
| 激活 | <p>是否激活此功能</p><p>(OFF / ON / Safety I/O)</p> | OFF |
| 停止功能 | <p>功能违规时的停止方式</p><p>(停止0 / 停止1 / 停止2 / 不停止)</p> | 停止1 |
| 动作调优 | <p>调优以使运动不超过TCP速度限制</p><p>(启用 / 禁用)</p> | 禁用 |
| 重新规划 | <p>是否根据输入信号使用速度调整功能</p><p>(启用 / 禁用)</p> | 禁用 |
| <p>限制</p><p>[mm/s]</p> | <p>TCP速度限制值</p><p>(0 ~ 50000)</p> | 50000 |
| <p>比率</p><p>[%]</p> | <p>在重新调整速度时使用的减速比</p><p>(0 ~ 100)</p> | 100 |
| <p>延迟时间</p><p>[ms]</p> | <p>通过重新调整速度改变速度时，在延迟时间后监控已更改的速度限制值</p><p>(0 ~ 1000)</p> | 1000 |
| <p>信号</p><p>[类型, 号码]</p> | <p>用于速度重新调整的输入信号</p><p>( [无, -] / [安全输入, 1~8] / [安全通信, 1~64] )</p> | 0 |

{% hint style="warning" %}
<strong>[注意]</strong>: 设置速度监控功能时，请务必考虑停止反应时间，并覆盖以防止碰撞和伤害。
{% endhint %}
