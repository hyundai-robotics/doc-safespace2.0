# 3.3.1.3 安全工具信息

安全工具信息由安全控制板用于计算机器人的速度和位置。您必须输入实际机器人所配备的工具信息。该工具信息必须与用于机器人控制的工具编号完全一致（**\[系统 > 3：机器人参数 > 1：工具数据]**）。


您可以在 **\[系统 > 8：安全系统 > 1：基本设置 > 3：安全工具信息]** 菜单中设置安全工具信息，并通过单击菜单底部的“加载工具数据”来加载用于机器人控制的工具信息。

<p align="center">
<img src="../../../_assets/3/tool_info_param.png"></img>
<em><p align="center">안전 툴 정보 설정 화면</p></em>
</p>


|  **参数** |                       **描述**                       |  **默认值**  |
| :-------: | :------------------------------------------------: | :-------------: |
| <p>重量</p><p>[kg]</p> | <p>刀具重量</p><p>(0.0 ~ 1000.0)</p> | 0.0 |
| <p>长度</p><p>[mm]</p> | <p>刀具长度</p><p>(-3000.0 ~ 3000.0)</p> | 0.0 |
| <p>中心</p><p>[mm]</p> | <p>刀具重心相对于法兰中心的位置</p><p>(-3000.0 ~ 3000.0)</p> | 0.0 |
| <p>惯性</p><p>[㎏·㎡]</p> | <p>刀具相对于刀具坐标的转动惯量</p><p>(0.0 ~ 2000.000)</p> | 0.0 |
| 加载刀具数据 | 根据刀具编号加载用于机器人控制的刀具信息的功能 | - |
| 复制 | 复制相应页面上输入的值的功能 | - |
| 粘贴 | 将复制页面上的值粘贴到相应页面上的功能 | - |

{% hint style="warning" %}
**\[注意]**：如果安全工具信息与机器人控制工具信息不符，将会出现警告/错误，且机器人将无法运行。操作机器人前，请务必核对实际工具信息与安全工具信息是否一致。
{% endhint %}
 
{% hint style="warning" %}
**\[注意]**：支持安全工具编号 0 至 15。如果您的系统使用工具信息 16 至 31，请将安全工具编号 0 与工具信息匹配。
{% endhint %}
