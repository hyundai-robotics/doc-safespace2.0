# 3.3.1.4 安全附加重量

安全附加重量信息由安全控制板用于计算机器人的扭矩。您必须输入实际安装在机器人上的附加重量信息。该信息必须与用于机器人控制的附加重量信息完全一致（**\[系统 > 3：机器人参数 > 7：各轴附加重量]**）。


* **\[系统 > 8：安全系统 > 1：基本设置 > 4：安全附加重量]** 您可以在菜单中设置安全附加重量信息，也可以通过单击菜单底部的“加载附加重量”来加载用于机器人控制的附加重量信息。


<p align="center">
<img src="../../../_assets/3/add_tool_param.png"></img>
<em><p align="center">안전 부가중량 설정 화면</p></em>
</p>


|  **参数** |                       **描述**                       |  **默认值**  |
| :-------: | :------------------------------------------------: | :-------------: |
| <p>重量</p><p>[kg]</p> | <p>刀具重量</p><p>(0.0 ~ 1000.0)</p> | 0.0 |
| <p>中心</p><p>[mm]</p> | <p>刀具重心相对于法兰中心的位置</p><p>(-3000.0 ~ 3000.0)</p> | 0.0 |
| <p>惯性</p><p>[kg·㎡]</p> | <p>刀具相对于其坐标系的转动惯量</p><p>(0.0 ~ 2000.000)</p> | 0.0 |
| 加载附加重量 | 用于加载机器人控制所需的附加重量信息的功能 | - |
| 复制 | 用于复制相应页面上输入的值的功能 | - |
| 粘贴 | 用于将复制页面中的值粘贴到相应页面的功能 | - |

{% hint style="warning" %}
**\[注意]**：如果安全重量信息与机器人控制所用的重量信息不符，将会出现警告/错误，且机器人将无法运行。请务必在操作机器人前核对重量信息与实际安装的重量是否一致。
{% endhint %}
 
{% hint style="warning" %}
**\[注意]**：安全附加配重数值范围为 0 至 2，每个数值对应系统附加配重的轴号（0-S 轴，1-H 轴，2-V 轴）。请根据轴号输入相应的安全参数数值。
{% endhint %}
