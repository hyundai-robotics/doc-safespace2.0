# 3.3.1 Grundeinstellungen

Die Sicherheitsparameter des Roboters umfassen Grenzwerte und Stoppmethoden zur Überwachung der Sicherheitsfunktionen.

Jede Sicherheitsfunktion kann mit verschiedenen Aktivierungsbedingungen, Stoppmethoden bei Überschreitung und Grenzwerten konfiguriert werden.

Sie können das Menü für die Grundeinstellungen der Sicherheitsfunktionen wie folgt aufrufen.

* **\[System > 8: Sicherheitssystem > 1: Grundeinstellungen]** 
****

Die folgenden Sicherheitsfunktionen können im Menü „Grundeinstellungen“ konfiguriert werden:

* **Allgemein**: Sicherheitsfunktionsaktivierung, Geschwindigkeit im manuellen Modus, Bremsweg und periodische Zeitüberwachung einstellen.
* **Stoppeinstellungen**: Stoppmethode (Stopp 0, Stopp 1, Stopp 2) entsprechend dem Stopptyp einstellen.
* **Informationen zu Sicherheitswerkzeugen**: Informationen zu Sicherheitswerkzeugen einstellen.
* **Zusatzgewicht für Sicherheit**: Zusatzgewicht für Sicherheit einstellen.
* **Wartung**: Den für die Wartung der Sicherheitsfunktionen erforderlichen Robotertestzyklus einstellen.

{% hint style="warning" %}
**\[Achtung]**: Bediener und Benutzer müssen vor der Konfiguration der Sicherheitsfunktionen des Roboters eine Risikobewertung durchführen, um die Sicherheit von Personal und Ausrüstung im Umfeld des Roboters zu gewährleisten. Konfigurieren Sie basierend auf den Ergebnissen der Bewertung Folgendes:

* Legen Sie ein Passwort fest, um unbefugte Änderungen an der Sicherheitskonfiguration zu verhindern.
* Konfigurieren Sie sicherheitsrelevante Funktionen und Schnittstellen.
* Überprüfen Sie die Richtigkeit der Einstellungen, bevor Sie den Roboter in Betrieb nehmen.
* Stellen Sie sicher, dass alle Konfigurationen und Einstellungen der Sicherheitsfunktionen der Risikobewertung entsprechen.
{% endhint %}
