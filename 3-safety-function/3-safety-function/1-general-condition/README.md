# 3.3.1 基本设置

机器人安全参数包括用于监控安全功能的限值和停止方法。

每个安全功能都可以配置不同的激活条件、违规停止方法和限值。

可通过以下方法访问安全功能基本设置菜单。

* **\[系统 > 8：安全系统 > 1：基本设置]**
****

以下安全功能可在基本设置菜单中配置：

* **常规**：设置安全功能激活、手动模式速度、停止距离和周期性时间监控。
* **停止设置**：根据停止类型设置停止方式（停止 0、停止 1、停止 2）。
* **安全工具信息**：设置安全工具信息。
* **安全附加重量**：设置安全附加重量。
* **维护**：设置安全功能维护所需的机器人测试周期。

{% hint style="warning" %}
**\[注意]**：操作人员和用户在配置机器人安全功能前必须进行风险评估，以确保机器人周围人员和设备的安全。根据评估结果，进行以下配置：

* 设置密码等，以防止未经授权更改安全配置。
* 配置安全相关功能和接口。
* 操作机器人前，验证设置的准确性。
* 确认所有安全功能配置和设置均符合风险评估要求。
{% endhint %}
