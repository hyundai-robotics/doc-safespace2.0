# 3.3.1.1 常规设置

设置机器人运行所需的基本功能（手动模式速度监控、停止时间和停止距离监控）的阈值。此外，配置是否完全启用机器人监控和区域监控功能。即使启用了机器人监控和区域监控功能，如果安全功能被禁用，监控功能也不会运行。如果发生监控违规，将立即触发配置的安全停止（停止 0、停止 1）。


您可以在 **\[系统 > 8：安全系统 > 1：基本设置 > 1：常规]** 菜单中访问距离值。

<p align="center">
<img src="../../../_assets/3/general.png"></img>
<em><p align="center">설정 화면</p></em>
</p>


|  **参数** |                       **说明**                       |  **默认设置**  |
| :-------: | :------------------------------------------------: | :-------------: |
| 安全功能 | <p>是否启用机器人监控和区域监控功能</p><p>(启用/禁用)</p> | 禁用 |
| <p>手动模式速度</p><p>[mm/s]</p> | <p>是否启用此功能</p><p>(10 ~ 250)</p> | 250 |
| <p>停止时间</p><p>[ms]</p> | <p>违反此功能时的停止方式</p><p>(100 ~ 2000)</p> | 2000 |
| - 运动调整 | <p>调整运动以满足停止时间限制</p><p>（启用/禁用）</p> | 禁用 |
| <p>停止距离</p><p>[毫米]</p> | <p>各关节是否激活</p><p>（50 ~ 2000）</p> | 2000 |
| - 运动调整 | <p>调整运动以满足停止距离限制</p><p>（启用/禁用）</p> | 禁用 |

{% hint style="warning" %}
**\[注意]**：即使安全功能设置为禁用，机器人使用所必需的功能（手动模式速度、停止时间、停止距离监控）也不会被禁用。
{% endhint %}

{% hint style="warning" %}
**\[注意]**：停止时间和停止距离是指执行 stop1 时机器人实际停止所需的时间和距离，如果超过设定值，则会立即激活 stop0。
{% endhint %}
