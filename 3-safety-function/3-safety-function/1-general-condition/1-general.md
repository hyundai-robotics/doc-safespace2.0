# 3.3.1.1 일반

로봇 사용시 필수로 동작하는 기능(수동 모드 속도 감시, 정지 시간, 정지 거리 감시)의 기준값을 설정합니다. 또한, 로봇 감시 기능과 영역 감시 기능의 전체적인 활성화 여부를 설정합니다. 로봇 감시 기능, 영역 감시 기능 설정에서 기능을 활성화해도 안전 기능을 비활성화로 설정하면 감시 기능이 동작하지 않습니다. 모니터링 위반 시에는 설정한 안전 정지(정지 0, 정지 1)가 즉시 활성화됩니다.


**\[시스템 > 8: 안전 시스템 > 1: 기본 설정 > 1: 일반]** 메뉴에서 파라미터 값을 설정할 수 있습니다.

<p align="center">
<img src="../../../_assets/3/general.png"></img>
<em><p align="center">설정 화면</p></em>
</p>


|  **파라미터** |                       **설명**                       |  **기본 설정값**  |
| :-------: | :------------------------------------------------: | :----------: |
| 안전 기능 |  <p>로봇 감시, 영역 감시 기능 활성화 여부</p><p>(활성화 / 비활성화)</p>  | 비활성화 |
| <p>수동 모드 속도</p><p>[mm/s]</p> | <p>기능 활성화 여부</p><p>(10 ~ 250)</p> | 250  |
| <p>정지 시간</p><p>[ms]</p> |   <p>기능 위반시 정지 방법</p><p>(100 ~ 2000)</p>  | 2000 |
|  - 모션 튜닝 |   <p>정지 시간 제한값을 만족하는 모션으로 튜닝</p><p>(활성화 / 비활성화)</p>  |  비활성화 |
| <p>정지 거리</p><p>[mm]</p> |   <p>각 관절의 활성화 여부</p><p>(50 ~ 2000)</p>  | 2000 |
|  - 모션 튜닝 |   <p>정지 거리 제한값을 만족하는 모션으로 튜닝</p><p>(활성화 / 비활성화)</p>  |  비활성화 |

{% hint style="warning" %}
**\[주의]**: 안전기능을 비활성화로 설정해도 로봇 사용시 필수로 동작하는 기능(수동 모드 속도, 정지 시간, 정지 거리 감시)는 비활성화 되지 않습니다.
{% endhint %}

{% hint style="warning" %}
**\[주의]**: 정지 시간과 정지 거리는 정지1 수행시 실제 로봇이 정지하기까지의 시간과 거리이며, 설정한 값을 넘어가면 즉시 정지0이 활성화됩니다.  
{% endhint %}
