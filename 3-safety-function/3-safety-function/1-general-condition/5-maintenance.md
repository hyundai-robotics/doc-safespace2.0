# 3.3.1.5 维护

“维护”菜单允许您设置主控测试和制动测试周期。定期监控每个机器人轴的初始位置和制动状态对于确保安全功能的正常运行至关重要。如果测试未能在设定的周期内完成，则会立即触发安全停止1。

要进行制动测试，

您可以在 **\[系统 > 8：安全系统 > 1：基本设置 > 5：维护]** 菜单中设置参数值。

<p align="center">
<img src="../../../_assets/3/maint_param.png"></img>
<em><p align="center">유지 보수 설정 화면</p></em>
</p>


|  **参数** |                       **描述**                       |  **默认值**  |
| :-------: | :------------------------------------------------: | :-------------: |
| <p>掌握执行周期</p><p>[h]</p> | <p>掌握测试执行周期</p><p>(2 ~ 720)</p> | 720 |
| <p>中断测试执行周期</p><p>[h]</p> | <p>中断测试执行周期</p><p>(2 ~ 720)</p> | 720 |


{% hint style="warning" %}
**\[注意]**：如果发生崩溃，我们建议执行一次主测试和一次中断测试。
{% endhint %}
