# 3.3.1.2 停止设置

为每个安全功能设置适当的安全停止类型。当发生安全违规时，安全停止功能使机器人停止到安全状态。有三种类型：所有类型的安全停止功能均符合 IEC 61800-5-2 的要求 4.2.2.4。

* **停止 0**：立即切断关节模块中所有电机的电源并停止。
* **停止 1**：关节模块中的所有电机减速，然后停止。然后切断电机的电源。
* **停止 2**：关节模块中的所有电机减速并激活 SOS（安全工作停止）。保持所有电机的电源。

因安全功能违规而导致的停止类型在功能特定参数设置菜单中设置。您可以根据 ISO 10218-1 要求的停止类型（紧急停止、保护停止、正常停止）设置停止方法。有关每个停止的信号输入，请参考 "[3.3.4 安全信号输入/输出](../../../3-safety-function/3-safety-function/4-safety-io/README.md)。" 您还可以设置在手动模式速度监控违规时应执行的停止方法。停止方法可以从停止 0 或停止 1 中选择。

您可以在 `[System > 10: Safety System > 1: General setup > 2: Safe Stop]` 菜单中设置参数值。

|  **参数** |                       **描述**                       |  **默认值**  |
| :-------: | :------------------------------------------------: | :-------------: |
| 紧急停止 | <p>选择在紧急停止情况下应用的停止类型</p><p>(停止 0, 停止 1)</p> | 停止 1 |
| 保护停止 | <p>选择在保护停止情况下应用的停止类型</p><p>(停止 0, 停止 1, 停止 2)</p> | 停止 1 |
| 正常停止 | <p>选择在正常停止情况下应用的停止类型</p><p>(停止 0, 停止 1)</p> | 停止 1 |
| 手动停止 | <p>选择在手动模式停止情况下应用的停止类型</p><p>(停止 0, 停止 1)</p> | 停止 1 |

{% hint style="warning" %}
<strong>[注意]</strong>: 每个功能的适当停止方法必须通过风险评估建立，并在操作前进行验证。 
{% endhint %}
