# 3.3.1 机器人监控功能

机器人安全参数由用于监控安全功能的限值及停止方法组成。

各安全功能可以保存并活用由激活条件、违规时停止方法以及限值组成的各种集合。

设置安全参数的菜单请通过以下方法进入：

* *\[시스템]***\[系统]按钮 > \[4: 应用参数 > 18: SafeSpace2.0 > Parameter setup > Robot restriction]****\[4: 응용 파라미터 > 18: SafeSpace2.0 > Parameter setup > Robot restriction]**
***


在机器人限制菜单中可以设置的安全功能如下：

* **关节位置：限制机器人各轴的运动范围，使其仅能在指定范围内运行。**: 로봇이 축별로 특정 범위 내에서만 동작할 수 있도록 범위를 제한
* **关节速度：限制机器人的动量，使其不能以各轴限制速度以上驱动。**: 축별 제한된 속도 이상으로 구동하지 못하게 하여 로봇의 운동량을 제한
* **关节停止监控：执行停止2后，确认各轴的异常运动，监控机器人的停止状态。**: 정지2 수행 후 축별로 비정상적인 움직임을 확인하여 로봇의 정지 상태를 감시
* **TCP速度：限制机器人在TCP基准下不能以限制速度以上驱动。**: TCP 기준에서 로봇이 제한된 속도 이상으로 구동하지 못하게 제한
* **Re plan**: 외부 입력에 따라 로봇의 속도를 조절하여 협동 운전 모드 중 [3.2.2 速度及位置监控](../../2-collaborative-operation-mode/2-speed-separation-monitoring.md) 수행
* **功率、碰撞检测：限制机器人与操作人员碰撞时的力和压力。**: 로봇과 작업자의 충돌 발생 시의 힘과 압력을 제한
* **动量：限制机器人与操作人员碰撞时的能量和冲击载荷。**: 로봇과 작업자의 충돌 발생 시의 에너지와 충격 하중을 제한


{% hint style="warning" %}
*\[注意]**：操作人员和用户为确保机器人周围人员和设备的安全，在构成机器人安全功能前必须执行风险评估，并根据评估结果设置以下事项：

* 通过设置密码等，防止未经许可的人员擅自更改安全构成。
* 设置安全相关功能及接口。
* 机器人启动前，确认设置内容的准确性。
* 确认所有安全功能的构成及设置是否符合风险评估。
{% endhint %}
