# 3.3.1.7 功率监控

该功能用于监控机器人产生的力是否超过允许值。当监控违规时，系统将立即激活安全停止（停止0、停止1、停止2）。

*\[系统 > 4: 应用参数 > 18: SafeSpace2.0 > 1: 安全功能 > 参数设置 > 机器人限制 > 功率监控]**菜单中，可以设置参数值。

![!功率监控设置界面](../../../_assets/power.png)

| **|  参数 | 　　　　　　　　　说明                                                  |  默认设定值  |** | 　　　　　　　　　**|  参数 | 　　　　　　　　　说明                                                  |  默认设定值  |**                                                  |  **|  参数 | 　　　　　　　　　说明                                                  |  默认设定值  |** |
| :------: | ---------------------------------------------------------------- | :---------: |
| Activation | <p>功能激活与否</p><p>(Off/On/Safety Input)</p> |   Off  |
| Stop function |   <p>功能违规时的停止方法</p><p>(Stop0, Stop1, Stop2, Non-stop)</p>  | Stop 1 |
| 功率 |   <p>机器人的功率限值</p><p>（80 ~ 1000 (W)）</p> | 1000 |

{% hint style="warning" %}
* 与运动能量成比例，速度高且负载大的情况下，机器人的冲击量可能会增大，因此机器人与外部物体碰撞时可能会发生相当程度的冲击。在协作空间内应保持安全的速度和有效载荷进行运行。
* 若将工具信息及附加重量设置为与实际不同，可能会发生误检测。使用该功能前，请确认各信息。
{% endhint %}
