# 1.6.2 停止监控

停止监控功能用于在机器人停止运行时，监控各轴是否有异常运动。当超出设定限值时，系统将立即激活停止0。

*\[系统 > 4: 应用参数 > 18: SafeSpace2.0 > 参数设置 > 机器人限制 > 关节SOS]**菜单中，可以设置参数值。

![!停止监控参数设置界面](<../../../_assets/joint_sos_param.png>)

|  **|  参数 |                       说明                       |  默认设定值  |** |                       **|  参数 |                       说明                       |  默认设定值  |**                       |  **|  参数 |                       说明                       |  默认设定值  |**  |
| :-------: | :------------------------------------------------: | :----------: |
| Activation | <p>功能激活与否</p><p>(Off/On/Safety Input)</p> |   Off  |
| Joint OnOff |   <p>各关节的激活与否</p><p>(On/Off)</p>  |  Off |
| tolerance |   <p>各关节的角度限值</p><p>(0.0 ~ 3.0 (deg))</p>  |  0.1 |

{% hint style="warning" %}
*\[注意]**：当停止监控参数违规时，请务必在重新启动前确认机器人的运动是否正常。
{% endhint %}
