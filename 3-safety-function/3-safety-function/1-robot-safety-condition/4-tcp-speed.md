# 3.3.1.4 TCP速度限制

以机器人坐标系为基准监控TCP速度的功能。当监控违规时，系统将立即激活安全停止（停止0、停止1、停止2）。

*\[系统 > 4: 应用参数 > 18: SafeSpace2.0 > 参数设置 > 机器人限制 > TCP速度限制]**菜单中，可以设置参数值。

![!TCP速度参数设置界面](../../../_assets/tcp_speed_param.png)

| **|  参数 | 　　　　　　　　　说明                                                  |  默认设定值  |** | 　　　　　　　　　**|  参数 | 　　　　　　　　　说明                                                  |  默认设定值  |**                                                  |  **|  参数 | 　　　　　　　　　说明                                                  |  默认设定值  |** |
| :------: | ---------------------------------------------------------------- | :---------: |
| Activation | <p>功能激活与否</p><p>(Off/On/Safety Input)</p> |   Off  |
| 安全停止 |   <p>功能违规时的停止方法</p><p>(Stop0, Stop1, Stop2, Non-stop)</p>  | Stop 1 |
| Replan |   <p>是否使用根据输入信号调节速度的功能</p><p>(On/Off)</p>  |  Off |
| 速度限值 |   <p>TCP速度限值</p><p>(0 ~ 50000 (mm/s))</p>  | 50000 |
| 减速率 |   <p>Replan时使用的减速率</p><p>(0 ~ 100 (%))</p>  | 0 |
| 延迟时间 |   <p>通过RePlan更改速度时，系统将在延迟时间结束后，以更改后的速度限值进行监控  </p><p>(0 ~ 1000(ms))</p>  | 0 |
| 输入信号分配 |   <p>用于Replan的输入信号</p><p>(0 ~ 16)</p>  |  0 |

{% hint style="warning" %}
*\[注意]**：设置速度监控功能时，请务必考虑停止响应时间，并盖上防护罩以预防碰撞和受伤。
{% endhint %}
