# 3.3.1.2 조인트 속도 설정

조인트 속도 설정 파라미터는 로봇의 조인트 속도를 감시하기 위한 한계값입니다. 한계값 위반 시에는 설정한 안전 정지(정지0, 정지1, 정지2)가 즉시 활성화됩니다.

<p align="center">
<img src="../../../_assets/joint_speed.PNG"></img>
<em><p align="center">조인트 속도 설정 예</p></em>
</p>

**\[시스템 > 8: 안전 시스템 > 2: 파라미터 설정 > 1: 로봇 제한 > 2: 조인트 속도]** 메뉴에서 파라미터 값을 설정할 수 있습니다.

<p align="center">
<img src="../../../_assets/joint_speed_param.png"></img>
<em><p align="center">조인트 속도 설정 파라미터 설정 화면</p></em>
</p>

|  **파라미터** |                       **설명**                       |  **기본 설정값**  |
| :-------: | :------------------------------------------------: | :----------: |
| 활성화 | <p>기능 활성화 여부</p><p>(무효 / 유효 / 안전 입출력)</p> |   무효  |
| 정지 방법 |   <p>기능 위반시 정지 방법</p><p>(정지 0 / 정지 1 / 정지 2 / 무정지)</p>  | 정지 1 |
| 모션 튜닝 |   <p>관절의 속도 제한값을 초과하지 않는 모션으로 튜닝</p><p>(활성화 / 비활성화)</p>  | 비활성화 |
| 조인트 활성화 |   <p>각 관절의 활성화 여부</p><p>(활성화 / 비활성화)</p>  | 비활성화 |
| 유형 |   <p>각 관절의 작동 유형</p><p>(회전 / 직동)</p>  | 회전 |
| <p>속도</p><p>[mm/s]</p> |   <p>각 관절의 속도 제한값</p><p>(0 ~ 5000)</p>  | 5000.0 |

{% hint style="warning" %}
**\[주의]**: 속도 감시 기능 설정시에는 반드시 정지 반응 시간을 고려하고 커버를 덮어 충돌 및 부상을 예방하십시오.
{% endhint %}
