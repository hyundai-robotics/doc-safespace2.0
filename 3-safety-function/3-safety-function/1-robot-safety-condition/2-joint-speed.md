# 3.3.1.2 关节速度限制

关节速度限制参数是用于监控机器人关节速度的限值。当限值违规时，系统将立即激活已设定的安全停止（停止0、停止1、停止2）。

![!图4 关节速度限制设置示例](../../../_assets/joint_speed.png)

*\[系统 > 4: 应用参数 > 18: SafeSpace2.0 > 参数设置 > 机器人限制 > 关节速度限制]**菜单中，可以设置参数值。

![!图5 关节速度限制参数设置界面](<../../../_assets/joint_speed_param.png>)

|  **|  参数 |                       说明                       |  默认设定值  |** |                       **|  参数 |                       说明                       |  默认设定值  |**                       |  **|  参数 |                       说明                       |  默认设定值  |**  |
| :-------: | :------------------------------------------------: | :----------: |
| Activation | <p>功能激活与否</p><p>(Off/On/Safety Input)</p> |   Off  |
| Stop function |   <p>功能违规时的停止方法</p><p>(Stop0, Stop1, Stop2, Non-stop)</p>  | Stop 1 |
| Joint OnOff |   <p>各关节的激活与否</p><p>(On/Off)</p>  |  Off |
| speed |   <p>各关节的速度限值</p><p>(0 ~ 5000 (mm/s))</p>  |  5000.0 |

{% hint style="warning" %}
*\[注意]**：设置速度监控功能时，请务必考虑停止响应时间，并盖上防护罩以预防碰撞和受伤。
{% endhint %}
