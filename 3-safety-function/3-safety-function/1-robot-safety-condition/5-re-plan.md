# 3.3.1.5 Re plan

Re plan是基于从外部安全传感器接收的输入信号调节机器人速度的功能。机器人将按对应于输入信号的减速率更改运行速度，并在延迟时间结束后，将以相应的速度监控TCP速度。若因延迟时间不足，或机器人减速未充分进行而造成TCP速度限值违规，系统将立即激活安全停止（停止0、停止1、停止2）。

*\[系统 > 4: 应用参数 > 18: SafeSpace2.0 > 1: 安全功能 > 参数设置 > 机器人限制 > Re plan]**菜单中，可以设置参数

![!raplan设置界面](../../../_assets/replan.png)

|  **|  参数 |                       说明                       |  默认设定值  |** |                       **|  参数 |                       说明                       |  默认设定值  |**                       |  **|  参数 |                       说明                       |  默认设定值  |**  |
| :-------: | :------------------------------------------------: | :----------: |
| Replan |   <p>是否使用根据输入信号调节速度的功能</p><p>(On/Off)</p>  |  Off |
| 速度限值 | <p>Replan以后的TCP速度限值</p><p>（0 ~ 50000 (mm/s)）</p> | 50000 |
| 减速率 |   <p>Replan时使用的减速率</p><p>(0 ~ 100 (%))</p>  | 0 |
| 延迟时间 |   <p>通过RePlan更改速度时，系统将在延迟时间结束后，以更改后的速度限值进行监控  </p><p>(0 ~ 1000(ms))</p>  | 0 |
| 输入信号分配 |   <p>用于Replan的输入信号</p><p>(0 ~ 16)</p>  |  0 |

{% hint style="warning" %}
* 设置速度限制时，请务必考虑停止时间，并加盖防护罩以预防碰撞和受伤。
* 与运动能量成比例，速度高且负载大的情况下，机器人的冲击量可能会增大，因此机器人与外部物体碰撞时可能会发生相当程度的冲击。在协作空间内应保持安全的速度和有效载荷进行运行。
{% endhint %}
