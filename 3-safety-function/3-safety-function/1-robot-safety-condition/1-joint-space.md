# 3.3.1.1 关节角度限制设置

关节限制参数是用于在机器人关节空间中监控安全功能的限值。当监控违规时，系统将立即激活已设定的安全停止（停止0、停止1、停止2）。

![!图4 关节角度限制设置示例（S轴）](<../../../_assets/joint_space.png>)

*\[系统 > 4: 应用参数 > 18: SafeSpace2.0 > 参数设置 > 机器人限制 > 关节角度限制]**菜单中，可以设置参数值。

![!图5 关节角度限制参数设置界面](<../../../_assets/joint_space_param.png>)

|  **|  参数 |                       说明                       |  默认设定值  |** |                       **|  参数 |                       说明                       |  默认设定值  |**                       |  **|  参数 |                       说明                       |  默认设定值  |**  |
| :-------: | :------------------------------------------------: | :----------: |
| Type |  <p>安全区域的类型</p><p>（工作区域/保护区域）</p>  | 工作区域 |
| Activation | <p>功能激活与否</p><p>(Off/On/Safety Input)</p> |   Off  |
| Stop function |   <p>功能违规时的停止方法</p><p>(Stop0, Stop1, Stop2, Non-stop)</p>  | Stop 1 |
| Joint OnOff |   <p>各关节的激活与否</p><p>(On/Off)</p>  |  Off |
| Min |   <p>各关节的角度限值</p><p>(-360.0 ~ 360.0 (deg))</p>  |  -360.0 |
| Max |   <p>各关节的角度限值</p><p>(-360.0 ~ 360.0 (deg))</p>  |  360.0 |

{% hint style="warning" %}
*\[注意]**：安全功能基于已设定的区域进行监控。设定区域时应考虑停止距离，驱动前必须进行验证。
{% endhint %}
