# 3.3.2.4 TCP方向监控

为使用TCP方向监控功能，可以设置用于生成基准向量的旋转角度和偏差角度，以设置用于监控的圆锥。

以机器人坐标系（![](../../_assets/1.png)）的Z方向向量为准，按设定的角度旋转来设置基准向量（![](../../_assets/3.png)），并根据其偏差角度（![](../../_assets/4.png)）对由各母线组成的圆锥体（![](../../_assets/2.png)）进行建模。该圆锥体的顶点（![](../../_assets/5.png)）位于TCP，如果TCP的Z方向向量（![](../../_assets/6.png)）超过监控圆锥体范围，则会发生TCP方向限制功能违规的错误。

![!图 TCP方向限制功能](../../../_assets/safety_layout/tool_ori.png)

*\[系统 > 4: 应用参数 > 18: SafeSpace2.0 > 参数设置 > 布局限制 > TCP方向]**菜单中，可以设置参数值。

![!图 TCP方向设置界面](../../../_assets/safety_layout/tool_ori_param.PNG)


|  **|  参数 |                       说明                       |  默认设定值  |** |                       **|  参数 |                       说明                       |  默认设定值  |**                       |  **|  参数 |                       说明                       |  默认设定值  |**  |
| :-------: | :------------------------------------------------: | :----------: |
| Activation | <p>功能激活与否</p><p>(Off/On/Safety Input)</p> |   Off  |
| Stop function |   <p>功能违规时的停止方法</p><p>(Stop0, Stop1, Stop2, Non-stop)</p>  | Stop 1 |
| Rx |   <p>X方向基准向量的旋转量</p><p>(-180.0 ~ 180.0 (deg))</p>  |  0.0 |
| Ry |   <p>Y方向基准向量的旋转量</p><p>(-180.0 ~ 180.0 (deg))</p>  |  0.0 |
| Rz |   <p>Z方向基准向量的旋转量</p><p>(-180.0 ~ 180.0 (deg))</p>  |  0.0 |
| 偏差角度 |   <p>TCP方向限值</p><p>(-180.0 ~ 180.0 (deg))</p>  |  0.0 |





{% hint style="warning" %}
*\[注意]**

* 更改工具数据时，请务必重新确认安全工具建模中所设置的参数是否准确。相同工具的工具数据编号与安全工具建模编号必须一致。
{% endhint %}
