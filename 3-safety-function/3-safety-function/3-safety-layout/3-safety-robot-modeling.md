# 3.3.2.3 安全机器人建模

用于安全空间监控的机器人模型。安全机器人建模可应用于2轴和3轴，全部以胶囊体形式建模。

用于安全机器人建模的胶囊由两端的球体中心和半径组成。建模的球体中心是机器人2轴/3轴中心位置，半径必须足够大以包括当前连杆的尺寸及最大TCP速度下的停止距离。

您可以在 **\[系统 > 8：安全系统 > 2：参数设置 > 2：区域限制 > 2：机器人建模]** 菜单中设置参数值。

| **参数** | 　　　　　　　　　**说明**                                     | **默认设定值** |
| :------: | --------------------------------------------------- | :--------: |
| <p>高度</p><p>[毫米]</p> | <p>平板高度</p><p>(0 ~ 5000.0)</p> | 0 |
| <p>半径</p><p>[毫米]</p> | <p>球体半径</p><p>(0 ~ 3000.0)</p> | 10 |
| <p>中心</p><p>[毫米]</p> | <p>中心位置</p><p>(-3000.0 ~ 3000.0)</p> | 0 |
| <p>方向</p><p>[度]</p> | <p>坐标系方向</p><p>(-180.0 ~ 180.0)</p> | 0 |                        |    0 mm    |

{% hint style="warning" %}
**\[注意]**

* 机器人布局设置的定义仅适用于机器人2轴和3轴，因此即使设置了安全区域，机器人的其他部分也可能侵入该区域。
{% endhint %}
