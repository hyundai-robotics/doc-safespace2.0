# 3.3.2.4 TCP方向监控

为使用TCP方向监控功能，可以设置用于生成基准向量的旋转角度和偏差角度，以设置用于监控的圆锥。

通过基于机器人坐标系 Z 方向向量 (![](../../../_assets/1.png)) 旋转设定角度，设置参考向量 (![](../../../_assets/3.png))，可以构建一个由母线组成的圆锥体 (![](../../../_assets/2.png))，这些母线之间的距离由偏差角 (![](../../../_assets/4.png)) 分隔。该圆锥体的顶点 (![](../../../_assets/5.png)) 位于 TCP 处。如果 TCP 的 Z 方向向量 (![](../../../_assets/6.png)) 穿过该监控圆锥体，则会发生 TCP 方向限制函数违例错误。

<p align="center">
<img src="../../../_assets/safety_layout/tool_ori.png"></img>
<em><p align="center">툴 방향 제한 기능</p></em>
</p>

您可以在 **\[系统 > 8：安全系统 > 2：参数设置 > 2：区域限制 > 4：工具方向]** 菜单中设置参数值。

<p align="center">
<img src="../../../_assets/safety_layout/tool_orient.png"></img>
<em><p align="center">툴 방향 설정 화면</p></em>
</p>

|  **参数** |                       **说明**                       |  **默认设定值**  |
| :-------: | :------------------------------------------------: | :----------: |
| 激活 | <p>功能是否激活</p><p>(无效 / 有效 / 安全 I/O)</p> | 无效 |
| 停止方法 | <p>功能违规时的停止方法</p><p>(停止 0 / 停止 1 / 停止 2 / 不停止)</p> | 停止 1 |
| <p>Org.Rx</p><p>[度]</p> | <p>参考向量相对于 X 方向的旋转量</p><p>(-180.0 ~ 180.0)</p> | 0.0 |
| <p>Org.Ry</p><p>[度]</p> | <p>参考向量相对于 Y 方向的旋转量</p><p>(-180.0 ~ 180.0)</p> | 0.0 |
| <p>Org.Rz</p><p>[度]</p> | <p>参考向量相对于 Z 方向的旋转</p><p>(-180.0 ~ 180.0)</p> | 0.0 |
| 偏差角 | <p>工具方向限制</p><p>(-180.0 ~ 180.0)</p> | 0.0 |
| 加载当前位置 <br> | 使用当前机器人位姿创建参考向量 | - |


{% hint style="warning" %}
**\[注意]**

* 更改工具数据时，请务必重新确认安全工具建模中所设置的参数是否准确。相同工具的工具数据编号与安全工具建模编号必须一致。
{% endhint %}
