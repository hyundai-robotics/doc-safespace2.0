# 3.3.3.5 自碰撞检测

您可以在 **\[系统 > 8：安全系统 > 2：参数设置 > 2：区域限制 > 5：自碰撞检测]** 菜单中设置机器人自碰撞检测功能的参数。

<p align="center">
<img src="../../../_assets/3/self_collision_param.png"></img>
<em><p align="center">自碰撞检测功能参数设置界面</p></em>
</p>

|  **参数** |                       **说明**                       |  **默认设定值**  |
| :-------: | :------------------------------------------------: | :----------: |
| 激活 | <p>功能是否激活</p><p>（无效 / 有效 / 安全 I/O）</p> | 无效 |
| 停止方法 | <p>违反功能时的停止方法</p><p>（停止 0 / 停止 1 / 停止 2 / 不停止）</p> | 停止 1 |
