# 3.3.3.5 Selbstkollisionserkennung

Die Parameter für die Selbstkollisionserkennung des Roboters können Sie im Menü **\[System > 8: Sicherheitssystem > 2: Parametereinstellungen > 2: Bereichsgrenzen > 5: Selbstkollisionserkennung]** festlegen.

<p align="center">
<img src="../../../_assets/3/self_collision_param.png"></img>
<em><p align="center">Bildschirm zur Einstellung der Parameter der Selbstkollisionserkennungsfunktion</p></em>
</p>

|  **Parameter** |                       **Beschreibung**                       |  **Standardeinstellung**  |
| :-------: | :------------------------------------------------: | :----------: |
| Aktivierung | <p>Funktionsstatus</p><p>(Ungültig / Gültig / Sichere E/A)</p> | Ungültig |
| Stoppmethode | <p>Stoppmethode bei Funktionsverletzung</p><p>(Stop 0 / Stop 1 / Stop 2 / Kein Stopp)</p> | Stopp 1 |
