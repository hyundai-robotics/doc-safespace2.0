# 3.3.3.1 安全区域设置

安全区域是用于监控工具及机器人连杆区域的工作空间或保护空间。工作空间是监控对象可以自由移动但不能离开的受限空间。与此不同，保护空间是监控对象进入后不能移动的受限空间。当机器人离开已设定的工作空间或侵入保护空间时，安全停止（停止0、停止1、停止2）将被激活。

<p align="center">
<img src="../../../_assets/safety_layout/cell_working.png"></img>
<em><p align="center">工作空间</p></em>
</p>

<p align="center">
<img src="../../../_assets/safety_layout/cell_protected.png"></img>
<em><p align="center">受保护空间</p></em>
</p>

安全区域的配置方法是：设置每个顶点相对于机器人坐标系的位置和高度。最多可以添加 10 个顶点。安全区域可通过参数设置或安全输入/输出信号激活。

您可以在 **\[系统 > 8：安全系统 > 2：参数设置 > 2：区域限制 > 1：区域]** 菜单的每个选项卡中设置安全区域的参数值。


* **一般的**

<p align="center">
<img src="../../../_assets/safety_layout/cell_general.png"></img>
<em><p align="center">一般的</p></em>
</p>

|  **参数** |                       **说明**                       |  **默认设定值**  |
| :-------: | :------------------------------------------------: | :----------: |
| 激活 | <p>功能激活与否</p><p>(开/关/安全输入)</p> |   离开  |
| 停止功能 |   <p>功能违规时的停止方法</p><p>(停止0、停止1、停止2、不停歇)</p>  | 停止1 |
| 类型 |  <p>安全区域的类型</p><p>（工作区域/保护区域）</p>  | 工作区域 |


* **检测目标**

<p align="center">
<img src="../../../_assets/safety_layout/cell_target.png"></img>
<em><p align="center">检测目标</p></em>
</p>

|  **参数** |                       **说明**                       |  **默认设定值**  |
| :-------: | :------------------------------------------------: | :----------: |
| 工具 | <p>工具建模监控</p><p>(开/关/安全输入)</p> |   离开  |
| 下臂 |   <p>机器人2轴建模监控</p><p>(关/开)</p>  | 离开 |
| 上臂 |  <p>机器人3轴建模监控</p><p>(关/开)</p>  | 离开 |


* **区域**

<p align="center">
<img src="../../../_assets/safety_layout/cell_working.png"></img>
<em><p align="center">区域</p></em>
</p>

|  **参数** |                       **说明**                       |  **默认设定值**  |
| :-------: | :------------------------------------------------: | :----------: |
| <p>Z轴最小值/最大值</p><p>[mm]</p> | <p>基于机器人坐标系的安全区域高度</p><p>(-5000.0 ~ 5000.0)</p> | 0 |
| 启用 | <p>是否启用安全区域顶点</p><p>(启用/禁用)</p> | 禁用 |
| <p>X轴</p><p>[mm]</p> | <p>基于机器人坐标系的顶点X轴位置</p><p>(-5000.0 ~ 5000.0)</p> | 0 |
| <p>Y轴</p><p>[mm]</p> | <p>基于机器人坐标系的顶点Y轴位置</p><p>(-5000.0 ~ 5000.0)</p> | 0 |



{% hint style="warning" %}
**\[注意]**：安全功能基于已设定的区域进行监控。设定区域时应考虑停止距离，驱动前必须进行验证。
{% endhint %}
