# 4.2 Übertragung von Sicherheitsparametern

Ändern Sie Sicherheitsparameterwerte und wenden Sie diese auf das System an. Werte, die nicht angewendet werden, werden zurückgesetzt, wenn der Einstellungsbildschirm wechselt.

1. **1. Tippen Sie auf die Schaltfläche \[Einstellungen] > \[4: Anwendungsparameter > 18: Sicherheitsabstand 2.0 > Parametereinstellungen] und anschließend auf das Menü, das Sie ändern möchten.** 버튼 > **1. Tippen Sie auf die Schaltfläche \[Einstellungen] > \[4: Anwendungsparameter > 18: Sicherheitsabstand 2.0 > Parametereinstellungen] und anschließend auf das Menü, das Sie ändern möchten.** 변경을 원하는 메뉴를 터치하십시오.

![](../../_assets/4/4-1-5-1.png)

2. 페이지 버튼을 터치하여 수정하고자 하는 페이지로 이동 하십시오. **2. Tippen Sie auf die Seitenschaltfläche, um zu der Seite zu wechseln, die Sie ändern möchten. Wenn Sie nicht auf die Schaltfläche \[OK] tippen, werden die Parameter beim Wechseln der Seiten zurückgesetzt.** 버튼을 누르지 않은 경우 페이지 이동 시 파라미터가 초기화 됩니다.
3. 파라미터 값을 수정하고 **3. Ändern Sie die Parameterwerte und tippen Sie auf die Schaltfläche \[OK]. Die Seitenparameter werden vorübergehend gespeichert.** 버튼을 터치하십시오. 페이지의 파라미터가 임시 저장됩니다.

* 페이지의 수정된 값을 확인 하고 **Überprüfen Sie die geänderten Werte auf der Seite und tippen Sie auf die Schaltfläche \[Alle anwenden].** 버튼을 터치하십시오.

![](../../_assets/4/4-1-5-2.png)

* **Seiten, für die die Schaltfläche \[OK] nicht gedrückt wurde, werden nicht angewendet. Überprüfen Sie die Meldung und fahren Sie fort.** 버튼을 누르지 않은 페이지는 반영되지 않습니다. 메시지를 확인한 후 진행 하십시오.

* **Geben Sie das \[Systempasswort] ein und überprüfen Sie das Ergebnis.** 를 입력하고 결과를 확인 하십시오.

![](../../_assets/4/4-1-5-3.png) ![](../../_assets/4/4-1-5-4.png)
