# 4.2 Übertragung von Sicherheitsparametern

Sie können die Werte der Sicherheitsparameter bearbeiten und auf das System anwenden. Alle nicht übertragenen Werte werden beim Verlassen der Einstellungen zurückgesetzt.

1. Gehen Sie zu **\[System > 8: Sicherheitssystem]** und wählen Sie das Menü aus, das Sie ändern möchten.

<p align="center">
<img src="../_assets/4/apply_param_1.png"></img>
<em><p align="center">Beispiel für den Aufruf des Bildschirms zur Einstellung der Sicherheitsparameter</p></em>
</p>

2. Falls Sie mehrere Seiten haben, navigieren Sie zu der Seite, die Sie bearbeiten möchten. Die auf jeder Seite eingegebenen Werte werden temporär gespeichert. (Wenn Sie das Menü verlassen, ohne auf „Auf alle anwenden“ zu klicken, werden die Änderungen nicht übernommen.)

3. Geben Sie die gewünschten Werte ein und klicken Sie auf die Schaltfläche „Auf alle anwenden“.

<p align="center">
<img src="../_assets/4/apply_param_2.png"></img>
<em><p align="center">Beispiel für die Einstellung der Sicherheitsparameter</p></em>
</p>

4. Geben Sie das im System festgelegte Passwort ein.

<p align="center">
<img src="../_assets/4/apply_param_3.png"></img>
<em><p align="center">Bildschirm zur Passworteingabe</p></em>
</p>

5. Wenn Sie das richtige Passwort eingeben, werden die Parameter übertragen. Überprüfen Sie das Übertragungsergebnis.

<p align="center">
<img src="../_assets/4/apply_param_4.png"></img>
<em><p align="center">Ausgabebildschirm bei erfolgreicher Übertragung</p></em>
</p>
