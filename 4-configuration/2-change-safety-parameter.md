# 4.2 安全参数传输

请修改安全参数值并应用到系统。未完成应用的值在设置界面更改时会被初始化。

1. **1. 请在\[设置]按钮 > \[4: 应用参数 > 18: 安全空间2.0 > 参数设置]中，触摸所要更改的菜单。** 버튼 > **1. 请在\[设置]按钮 > \[4: 应用参数 > 18: 安全空间2.0 > 参数设置]中，触摸所要更改的菜单。** 변경을 원하는 메뉴를 터치하십시오.

![](../../_assets/4/4-1-5-1.png)

2. 페이지 버튼을 터치하여 수정하고자 하는 페이지로 이동 하십시오. **2. 请触摸页面按钮移动到所要修改的页面。如果未按\[确认]按钮，页面移动时参数会被初始化。** 버튼을 누르지 않은 경우 페이지 이동 시 파라미터가 초기화 됩니다.
3. 파라미터 값을 수정하고 **3. 请修改参数值后触摸\[确认]按钮。页面的参数会被临时保存。** 버튼을 터치하십시오. 페이지의 파라미터가 임시 저장됩니다.

* 페이지의 수정된 값을 확인 하고 **请确认页面的修改值后触摸\[全部应用]按钮。** 버튼을 터치하십시오.

![](../../_assets/4/4-1-5-2.png)

* **未按\[确认]按钮的页面不会反映。请确认消息后继续进行。** 버튼을 누르지 않은 페이지는 반영되지 않습니다. 메시지를 확인한 후 진행 하십시오.

* **请输入\[系统密码]并确认结果。** 를 입력하고 결과를 확인 하십시오.

![](../../_assets/4/4-1-5-3.png) ![](../../_assets/4/4-1-5-4.png)
