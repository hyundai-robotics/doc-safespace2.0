# 4.1.2 证书颁发

安全参数通过证书保护。为了确保保存的安全参数，您首先需要获得一个证书。
检查证书状态并进行删除和颁发需要系统密码。

1. 点击 `[System > 8: Safety System 4: Certificate]` 菜单。

<p align="center">
<img src="../../_assets/4/certificate.png"></img>
<em><p align="center">安全特性证书设置屏幕</p></em>
</p>

* 检查证书状态
`[Check]` 触摸按钮。
输入系统密码。
检查结果。

* 颁发证书。
`[Issue]` 触摸按钮。
输入系统密码。
检查结果。

* 丢弃证书。
`[Discard]` 触摸按钮。
输入系统密码。
检查结果。
