# 4.1.4 认证书发放

安全参数通过证书受到保护。为了保护已保存的安全参数的安全，首先必须获得认证书。
要确认认证状态，或删除/发放认证，就需要输入系统密码。

1. 点击 **\[系统 > 8：安全系统 4：证书]** 菜单。

<p align="center">
<img src="../../_assets/4/certificate.png"></img>
<em><p align="center">安全功能证书设置屏幕</p></em>
</p>

* 确认认证状态
请触摸 **\[确认]** 按钮。
请输入系统密码。
请\确认结果。

* 发放认证书
请触摸 **\[发放]** 按钮。
请输入系统密码。
请确认结果。

* 废弃认证书
请触摸 **\[废弃]** 按钮。
请输入系统密码。
请确认结果。
