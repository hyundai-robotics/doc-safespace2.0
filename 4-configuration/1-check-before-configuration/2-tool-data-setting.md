# 4.1.2 工具数据设置

安全功能监控整个机器人系统，包括连接到机器人法兰上的工具。因此，工具数据与实际值的误差越小，安全功能就会更准确地运行。请以法兰坐标系为基准设置工具的长度及角度，并按单位输入工具的重量、重心及惯性信息。

1. 请将运行方式设置为手动模式。
2. 请按下紧急停止开关来切断电机电源。
3. 请触摸 **\[设置]按钮** > **\[3: 机器人参数 > 1: 工具数据]菜单**。
4. 请确认各轴数据，并设置工具的重量、重心和惯性后，触摸 **\[OK]** 按钮保存。

![](../../_assets/image20.jpeg)

* 要创建新的工具数据或利用现有程序来简单创建工具数据，请触摸 **\[自动校正]按钮**。
* 要校正工具角度，请触摸 **\[角度校正]按钮**。
* 要添加新的用户坐标系或删除用户坐标系，请使用 **\[+]**/**\[-]**按钮。
* 要查看并编辑工具数据的详细信息，请在工具数据列表中选择所需名称。
* 要复制工具数据信息并粘贴到其他工具数据，请使用 **\[页面复制]**/**\[页面粘贴]按钮**。

{% hint style="info" %}
* 如果无法获取刀具的重量和重心信息，您可以使用负载估算功能来估算这些值。
* 有关设置刀具数据的详细信息，请参阅[**Hi6 控制器操作手册**](https://hrbook-hrc.web.app/#/view/doc-hi6-operation/korean-tp630/README)。
{% endhint %}
