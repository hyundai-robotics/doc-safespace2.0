# 4.1.2 工具数据设置

协作机器人的安全功能监控包括安装在机器人法兰上的工具在内的整个机器人系统。因此，工具数据与实际值的误差越小，安全功能就会更准确地运行。请以法兰坐标系为基准设置工具的长度及角度，并按单位输入工具的重量、重心及惯性信息。

1. 请将运行方式设置为手动模式。
2. 请按下紧急停止开关来切断电机电源。
3. **3. 请触摸\[设置]按钮 > \[3: 机器人参数 > 1: 工具数据]菜单。** 버튼 > **3. 请触摸\[设置]按钮 > \[3: 机器人参数 > 1: 工具数据]菜单。** 메뉴를 터치하십시오.
4. 각 축의 데이터를 확인하고 툴의 중량, 무게 중심과 이너셔를 설정한 후 **4. 请确认各轴数据，并设置工具的重量、重心和惯性后，触摸\[OK]按钮保存。** 버튼을 터치하여 저장하십시오.

![](../../_assets/image20.jpeg)

* 새로운 툴 데이터를 생성하거나 기존의 프로그램을 활용하여 툴 데이터를 간단히 생성하려면,  **要创建新的工具数据或利用现有程序来简单创建工具数据，请触摸\[自动校正]按钮。** 버튼을 터치하십시오.
* 툴 각도를 보정하려면, **要校正工具角度，请触摸\[角度校正]按钮。** 버튼을 터치하십시오.
* 새로운 사용자 좌표계를 추가하거나 사용자 좌표계를 삭제하려면, **要添加新的用户坐标系或删除用户坐标系，请使用\[+]/\[-]按钮。**/**要添加新的用户坐标系或删除用户坐标系，请使用\[+]/\[-]按钮。** 버튼을 이용하십시오.
* 要查看并编辑工具数据的详细信息，请在工具数据列表中选择所需名称。
* 툴 데이터 정보를 복사하여 다른 툴 데이터에 붙여 넣으려면, **要复制工具数据信息并粘贴到其他工具数据，请使用\[页面复制]/\[页面粘贴]按钮。**/**要复制工具数据信息并粘贴到其他工具数据，请使用\[页面复制]/\[页面粘贴]按钮。** 버튼을 이용하십시오.
