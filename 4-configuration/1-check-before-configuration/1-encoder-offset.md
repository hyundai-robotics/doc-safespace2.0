# 4.1.1 编码器检查

安全功能基于安装在各轴上的编码器数据来诊断机器人的位置和速度，因此编码器数据的准确性很重要。因此，在使用安全功能前必须检查编码器值与实际值是否一致。

1\. 请确认机器人各轴的原点刻度后移动轴。


因安全功能违规而发生停止时，请在手动模式状态下通过点动移动各轴。有关恢复方法的详细内容，请参阅 "[**6.1 恢复模式**](../../6-recovery/README.md)”。

2\. 在作业区域的姿势信息窗口中，请检查机器人的轴坐标值是否显示为基准姿势（**0, 90, 0, 0, 0, 0** \[deg]）。


* 如果作业区域中没有姿势信息窗口，请触摸面板堆栈右上角的 **\[+]**按钮，然后在面板选择窗口中触摸 **\[姿势]**。


3\. 若角度值的误差在0.01以内，则进行下一步；若误差超过0.01，则执行编码器偏移。

4\. 请重新启动系统。

{% hint style="info" %}
有关编码器偏移的更多信息，请参阅“[**Hi6 控制器操作手册**](https://hrbook-hrc.web.app/#/view/doc-hi6-operation/korean-tp630/7-system/4-robot-parameter/4-encoder-offset/README)”中的“[**7.4.4 编码器偏移**](https://hrbook-hrc.web.app/#/view/doc-hi6-operation/korean-tp630/README)”。
{% endhint %}
