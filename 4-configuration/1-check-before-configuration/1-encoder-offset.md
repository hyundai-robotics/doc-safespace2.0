# 4.1.1 编码器检查

安全功能基于安装在各轴上的编码器数据来诊断机器人的位置和速度，因此编码器数据的准确性很重要。因此，在使用安全功能前必须检查编码器值与实际值是否一致。

1\. 请确认机器人各轴的原点刻度后移动轴。


안전 기능 위반으로 정지 발생 시 수동 모드 상태에서 조그로 각 축을 이동시키십시오. 복구 방법에 대한 자세한 내용은 “[因安全功能违规而发生停止时，请在手动模式状态下通过点动移动各轴。有关恢复方法的详细内容，请参阅“**6.1 恢复模式**”。](../../6-recovery/README.md)”를 참조하십시오.

2\. 작업 영역의 포즈 정보창에서 로봇의 축좌표 값이 기준 자세(**2\. 在作业区域的姿势信息窗口中，请检查机器人的轴坐标值是否显示为基准姿势（0, 90, 0, 0, 0, 0 \[deg]）。** \[deg])로 표시되는지 확인하십시오.


* 작업 영역에 포즈 정보창이 없으면, 패널 스택 우측 상단의 **如果作业区域中没有姿势信息窗口，请触摸面板堆栈右上角的\[+]按钮，然后在面板选择窗口中触摸\[姿势]。** 버튼을 터치한 후 패널 선택창에서 **如果作业区域中没有姿势信息窗口，请触摸面板堆栈右上角的\[+]按钮，然后在面板选择窗口中触摸\[姿势]。**를 터치하십시오.


3\. 若角度值的误差在0.01以内，则进行下一步；若误差超过0.01，则执行编码器偏移。

4\. 请重新启动系统。
