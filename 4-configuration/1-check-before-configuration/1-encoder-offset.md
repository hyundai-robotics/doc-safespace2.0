# 4.1.2 编码器检查

由于安全功能根据装载在每个轴上的编码器的数据诊断机器人的位置和速度，因此编码器数据的准确性非常重要。因此，在使用安全功能之前，您应检查编码器值是否与实际值匹配。

1\. 检查每个机器人轴的原点位置标记并移动轴。

当由于安全功能违规而发生停止时，请在手动模式下通过手动移动每个轴。有关恢复方法的详细信息，请参阅 "[6.1 恢复模式](../../6-recovery/README.md)"。

2\. 在工作区域的姿态信息窗口中，验证机器人的轴坐标值是否显示为参考姿势 (**0, 90, 0, 0, 0, 0** \[deg\])。

* 如果工作区域中没有姿态信息窗口，请触摸面板堆栈右上角的 `[+]` 按钮，然后在面板选择窗口中触摸 `[姿态]`。

3\. 如果角度值误差在 0.01 以内，请继续下一步。如果误差超过 0.01，请进行编码器偏移。

4\. 重新启动系统。
