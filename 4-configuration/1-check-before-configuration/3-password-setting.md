# 4.1.3 密码设置

安全功能的参数必须由指定负责人设置和管理。被指定为管理员的用户被授予管理员权限和系统设置密码。系统设置密码是设置安全功能参数时的必填项，密码错误时无法更改和设置参数。

1. **1.请触摸\[设置]按钮 > \[5: 初始化 > 11: 系统密码设置]菜单，即会出现密码设置窗口。** 버튼 > **1.请触摸\[设置]按钮 > \[5: 初始化 > 11: 系统密码设置]菜单，即会出现密码设置窗口。** 메뉴를 터치하십시오. 비밀번호 설정창이 나타납니다.
2. 비밀번호를 입력한 후 **2. 输入密码后，请触摸\[确认]按钮。** 버튼을 터치하십시오.

![](../../_assets/4/4-1-3-1.png)

* 设置安全功能的参数时，务必输入系统设置密码才能保存更改内容。

{% hint style="warning" %}
* 建议设置4位以上的密码。
* 如果忘记密码，请咨询工程师。
{% endhint %}
