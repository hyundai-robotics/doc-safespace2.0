# 4.1.3 密码设置

安全功能的参数必须由指定负责人设置和管理。被指定为管理员的用户被授予管理员权限和系统设置密码。系统设置密码是设置安全功能参数时的必填项，密码错误时无法更改和设置参数。

1. 点击 **\[统 > 5：重置 > 11：设置系统密码]** 菜单。密码设置窗口将会出现。
2. 输入密码后，请触摸 **\[确认]** 按钮。

<img src="../../_assets/4/input_password.png"></img>
<em><p align="center">密码设定画面</p></em>
</p>

* 设置安全功能的参数时，务必输入系统设置密码才能保存更改内容。

{% hint style="warning" %}
* 建议设置4位以上的密码。
* 如果忘记密码，请咨询工程师。
{% endhint %}
