{% hint style="warning" %}
**\[警告]** : 不要移动附加在控制器上的铭牌、警告标志、安全符号、名称标记、线缆标记等的位置，也不要用油漆或覆盖物覆盖它们。任何损害安全标签的行为都是禁止的。
{% endhint %}

{% hint style="warning" %}
**\[注意]** : 机器人安装区域和危险区域应通过不同的形状、颜色和风格与其他设施和设备明确区分开来。
{% endhint %}
