# 5. Überwachung des Sicherheitsstatus

Überwachen Sie Verstöße gegen Sicherheitsfunktionen und den Status der SCM-Platine (Safety Control Module). Sie können den Status der Roboterüberwachungsfunktionen und die Statusinformationen der Sicherheitsein- und -ausgänge überprüfen.

Über das Menü \[System > 4: Anwendungsparameter > 18: SafeSpace2.0 > Überwachung]* Überprüfen Sie dies im Menü.
