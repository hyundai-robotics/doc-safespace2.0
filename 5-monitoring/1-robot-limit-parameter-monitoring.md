# 5.1 机器人监控功能监控

选择*\[系统 > 4: 应用参数 > 18: SafeSpace2.0 > Monitoring] > [机器人监控]**菜单，检查机器人监控功能的状态。

![!机器人安全状态](../_assets/mon_robot.PNG)


* 检查机器人监控功能的状态。
  * **\[TCP位置]：TCP位置监控违规与否**: TCP 위치 모니터링 위반 여부
  * **\[TCP速度]：TCP速度监控违规与否**: TCP 속도 모니터링 위반 여부
  * **\[TCP方向]：TCP方向监控违规与否**: TCP 방향 모니터링 위반 여부
  * **\[功率]：功率监控违规与否**: 파워 모니터링 위반 여부
  * **\[动量]：动量监控违规与否**: 모멘텀 모니터링 위반 여부
  * **\[碰撞]：碰撞监控违规与否**: 충돌 모니터링 위반 여부
  * **\[SOS]：（安全停止监控）SOS监控违规与否**: (안전 정지 감시) SOS 모니터링 위반 여부
  * **\[关节位置]：关节位置监控违规与否**: 조인트 위치 모니터링 위반 여부
  * **\[关节速度]：关节速度监控违规与否**: 조인트 속도 모니터링 위반 여부
