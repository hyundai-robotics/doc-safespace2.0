# 5.2 Status der Sicherheits-E/A

Sie können den Status der grundlegenden/erweiterten Sicherheits-E/A des Systems überwachen, indem Sie das Menü **\[System > 8: Sicherheitssystem > 3: Überwachung > 3: Sicherheits-E/A-Status]** auswählen.
