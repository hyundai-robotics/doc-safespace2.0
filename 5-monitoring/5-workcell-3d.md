# 1.7.4 Workcell 3D

可在Workcell 3D中直接监控已在安全布局中设定的参数。Workcell 3D将安全布局中设置的安全区域、工具建模、机器人建模以三维方式可视化，可以确认设置。此外，实时反映机器人的位置，可以确认机器人的安全违反与否。

Workcell 3D功能可在作业程序作业区域的面板选择窗口中激活。

1\. 작업 영역의 패널 스택 우측 상단의 **1\. 请触摸作业区域面板堆栈右上角的\[+]按钮。** 버튼을 터치하십시오.

![](../../_assets/image41.jpeg)

2\. 패널 선택창에서 **2\. 请在面板选择窗口中触摸\[workcell]。机器人的当前姿势会显示在3D画面中。**을 터치하십시오. 로봇의 현재 자세가 3D 화면에 나타납니다.

![](../../_assets/image42.jpeg)

{% hint style="info" %}
* All items that can be monitored appear in the panel selection window.
* Items that can be monitored appear differently depending on the controller settings.
{% endhint %}

3\. 请确认作业区域（![](../../_assets/1.png)）、工具区域（![](../../_assets/2.png)）、工具方向约束（![](../../_assets/3.png)）、机器人肘部区域（![](../../_assets/4.png)）、禁止区域（![](../../_assets/5.png)）的设置状态。

![](../../_assets/image43.jpeg)

* 카메라를 조정하려면 3D 화면 우측 하단의 **要调整摄像头，请选择3D画面右下方的\[放大/缩小]图标（![](../../_assets/image44.png)）、\[移动]图标（![](../../_assets/image45.png)）或\[旋转]图标（![](../../_assets/image46.png)）后拖动画面。** 아이콘(![](../../_assets/image44.png)), **要调整摄像头，请选择3D画面右下方的\[放大/缩小]图标（![](../../_assets/image44.png)）、\[移动]图标（![](../../_assets/image45.png)）或\[旋转]图标（![](../../_assets/image46.png)）后拖动画面。** 아이콘(![](../../_assets/image45.png)), 또는 **要调整摄像头，请选择3D画面右下方的\[放大/缩小]图标（![](../../_assets/image44.png)）、\[移动]图标（![](../../_assets/image45.png)）或\[旋转]图标（![](../../_assets/image46.png)）后拖动画面。** 아이콘(![](../../_assets/image46.png))을 선택한 후 화면을 드래그하십시오.
* 要更改设置并应用设定值，请关闭workcell窗口后重新打开。

{% hint style="warning" %}
*\[注意]**：请对比Workcell模拟与实际机器人的位置，并确认周围的障碍物情况，以确保机器人安全运行。
{% endhint %}
