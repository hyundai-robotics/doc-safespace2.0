# 1.7.4 工作单元 3D

直接监控在工作单元 3D 中安全布局中设定的参数。工作单元 3D 可视化安全区域、工具建模和在安全布局中设定的机器人建模，以便您可以检查设置。它还实时反映机器人的位置，以便您可以检查机器人是否违反安全规定。

您可以在工作程序工作区域的面板选择窗口中激活工作单元 3D 功能。

1\. 点击工作区域面板堆栈右上角的 **\[+]** 按钮。

![](../../_assets/image41.jpeg)

2\. 在面板选择窗口中点击 **\[工作单元]**。机器人的当前姿态出现在 3D 屏幕上。

![](../../_assets/image42.jpeg)

{% hint style="info" %}
* * 所有可以监控的项目在面板选择窗口中出现。
* * 可以监控的项目根据控制器的设置显示不同。
{% endhint %}

3\. 检查工作区域 (![](../../_assets/1.png))、工具区域 (![](../../_assets/2.png))、工具方向约束 (![](../../_assets/3.png))、机器人肘部区域 (![](../../_assets/4.png)) 和禁区 (![](../../_assets/5.png)) 的设置状态。

![](../../_assets/image43.jpeg)

* 要调整相机，请选择 3D 屏幕右下角的 **\[放大/缩小]** 图标 (![](../../_assets/image44.png))、**\[移动]** 图标 (![](../../_assets/image45.png)) 或 **\[旋转]** 图标 (![](../../_assets/image46.png))，然后拖动屏幕。
* 要应用更改的设置，请关闭工作单元窗口并重新打开它。

{% hint style="warning" %}
**\[注意]**：将工作单元仿真与实际机器人的位置进行比较，并识别周围障碍，以安全操作机器人。
{% endhint %}
